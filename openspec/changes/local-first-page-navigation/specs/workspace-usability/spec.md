# Spec Delta

## MODIFIED Requirements

### Requirement: 新版本自動整頁載入

系統 SHALL 在站內換頁時於背景偵測伺服器是否已部署不同版本的入口程式，版本查詢 MUST 不阻塞已下載頁面的顯示與本機編輯。偵測到新版時 MUST 先保存目前頁面包含查詢期間產生的本機修改，再整頁載入使用者最後選擇的目標頁；保存失敗 MUST 保留目前畫面並顯示錯誤，不得強制重新載入。無法偵測版本時 SHALL 照常使用站內頁面。

#### Scenario: 部署後的下一次換頁
- **自動化驗證**: `UX-20`；Playwright：先下載目標頁並設置記憶體標記，攔住入口 HTML 查詢，斷言回應前目標頁已可編輯；輸入並等待本機保存後釋放不同 module script 路徑回應，斷言標記消失且目標頁與新文字保留；另讓查詢失敗，斷言站內頁面可用且標記保留。
- **WHEN** 分頁開啟期間伺服器已更新版本，使用者切換頁面
- **THEN** 先使用本機頁面，發現新版後保存本機修改並以新版程式載入最後選擇的目標頁

#### Scenario: 新版載入前本機保存失敗
- **自動化驗證**: `LFN-01`；Playwright：在背景版本查詢期間輸入，再注入本機寫入失敗並釋放新版回應，斷言未整頁載入、輸入仍在畫面且有保存錯誤提示。
- **WHEN** 偵測到新版但當下草稿無法保存
- **THEN** 保留目前內容及錯誤回饋，避免重新載入遺失尚未保存的字

### Requirement: 已下載頁面本機優先開啟

系統 SHALL 在開啟裝置已下載、可識別為目前本機擁有者的頁面時，優先呈現本機標題與正文並允許編輯，不得等待頁面資訊、程式版本或雲端同步完成。此行為 SHALL 適用站內連結、上一頁／下一頁及應用程式啟動後的直接開啟；今天日記入口僅在本機具備 Asia/Taipei 今天日期的有效對應時使用快取，不得開啟前一天日記冒充今天。已知登入失效或明確登出後 MUST 不以本機優先流程繞過登入畫面。

驗證期間的內文修改 SHALL 先保存本機，雲端狀態 SHALL 顯示同步中或離線，MUST 不宣稱已儲存於雲端，也不得把正常等待呈現為連線失敗。取得有效登入、相同擁有者、可存取頁面與相同內容版本的確認後，才允許同步並等待持久保存確認。尚未下載、索引或正文不可讀、擁有者不符的快取 MUST 不冒充可用文件；線上時改走雲端載入，離線時顯示明確限制。尚未下載的頁面 MUST 等待雲端同步後才允許編輯。

#### Scenario: 雲端連線緩慢時開啟已下載頁面
- **自動化驗證**: `UX-21`；Playwright：先開啟並保存頁面，再讓同步 WebSocket 延後 3 秒連到伺服器並重新整理，斷言 2 秒內顯示可編輯與原內容、雲端狀態為同步中且未出現重試按鈕；輸入後最終顯示雲端已儲存，以新 context 開啟斷言伺服器已有文字。
- **WHEN** 使用者在雲端連線緩慢時開啟曾開過的頁面
- **THEN** 可閱讀與編輯本機內容，同步在背景完成並保存

#### Scenario: 未下載頁面仍等待雲端
- **自動化驗證**: `UX-22`；Playwright：在沒有本機快取的新 context 中讓同步 WebSocket 延後 2.5 秒，開啟已有內容頁面，斷言 1.5 秒時尚未顯示可編輯的編輯器，連線後顯示可編輯且內容完整。
- **WHEN** 使用者在新裝置開啟尚未下載的頁面
- **THEN** 等雲端內容到達後才顯示編輯器，不先出現空白可編輯內容

#### Scenario: 網路請求未回應仍能切頁寫作
- **自動化驗證**: `LFN-02`；Playwright：預置並下載甲乙頁，攔住版本與頁面資訊請求至少 3 秒；以側欄切到乙後 500 毫秒內斷言本機標題、正文與可編輯狀態，於驗證前輸入新文字，之後等待本機保存並確認請求仍未釋放、目標頁無同步連線；釋放驗證後以新 context 斷言新文字已保存。500 毫秒由點擊開始計算，fixture 為 20 個短段落、無圖片；此門檻驗證受控環境，不宣稱所有裝置的延遲保證。
- **WHEN** 已下載頁面的版本及頁面資訊請求仍在等待
- **THEN** 不因網路等待持續停留在準備畫面，可立即編輯並保存本機

#### Scenario: 返回與直接開啟同樣使用本機內容
- **自動化驗證**: `LFN-03`；Playwright：下載長頁並記錄捲動位置，攔住頁面 API；上一頁／下一頁斷言回應前正確正文與位置恢復；重新整理及今天入口另斷言程式啟動後、API 回應前可編輯；固定日期跨午夜，斷言沒有今天快取時不顯示昨天為今天。
- **WHEN** 使用者返回已下載頁面或直接開啟具有有效快取的頁面／今天日記
- **THEN** 不等頁面資訊回應即可使用正確本機內容，並維持既有捲動行為

#### Scenario: 不可用快取與已知登出
- **自動化驗證**: `LFN-04`；Playwright：參數化缺少正文、損毀索引、不同擁有者與已知登入失效狀態；攔住雲端回應，斷言不出現錯誤快取正文或空白可編輯器；前三項線上釋放有效資料後顯示正確正文、離線顯示限制；已知失效時顯示登入且不重新開啟快取編輯器。
- **WHEN** 本機沒有可安全使用的目標文件，或已知登入失效
- **THEN** 不以錯誤快取開啟可編輯頁面，改用雲端載入、離線限制或登入流程

## ADDED Requirements

### Requirement: 本機優先頁面的背景驗證與草稿保護

系統 MUST 在背景驗證完成前阻止該頁任何同步更新離開裝置。若驗證確認登入失效、頁面刪除、無權限、擁有者不符或內容版本改變，MUST 停止該頁編輯與同步，保存包含驗證期間輸入的本機草稿並提供適用的登入、檢視、還原或另存入口；不得將草稿寫入其他擁有者或新版本文件。網路錯誤與伺服器暫時失敗 SHALL 保持本機編輯與重試能力。驗證成功時 SHALL 在原編輯畫面開始同步、更新頁面資訊，保留焦點與選取，不因驗證結果重建正文。快速切換時 MUST 捨棄已離開頁面的遲到結果與連線，維持內容獨立及最多一條目前頁面的同步連線。

#### Scenario: 驗證期間編輯後發現不可同步
- **自動化驗證**: `LFN-05`；Playwright＋Workers 整合：攔住已下載頁面的驗證，輸入文字並保存本機，再分別使登入到期、刪頁、撤銷權限、改變擁有者或以備份還原改變版本；釋放結果後斷言編輯停止、對應提示存在、未建立可傳輸舊更新的同步連線、伺服器原／新版本不含新字；以原擁有者重新登入或草稿檢視斷言新字仍在。
- **WHEN** 背景檢查確認本機文件已無法按原權限或版本同步
- **THEN** 保留本機草稿並阻止寫回，讓使用者依原因採取下一步

#### Scenario: 暫時失敗後恢復
- **自動化驗證**: `LFN-06`；Playwright：參數化驗證請求斷線與 500，斷言正文仍可編輯、本機保存成功、雲端非成功狀態；恢復有效回應並重試，斷言原編輯器節點、焦點與選取保留，遠端標題更新，最終取得持久確認且新 context 可見修改。
- **WHEN** 背景驗證暫時失敗後恢復，且權限及版本仍一致
- **THEN** 本機寫作不中斷，恢復後在原編輯畫面完成同步

#### Scenario: 快速換頁時驗證與版本回應亂序
- **自動化驗證**: `LFN-07`；Playwright：下載甲乙頁，控制甲→乙→甲→乙的頁面及版本請求亂序回應，包含過期頁面的 401／版本不符與新版入口結果；斷言最後仍為乙、甲的結果不改變乙狀態、最多一條有效同步連線；在乙輸入後斷言甲無新字、乙保留新字，即使新版引發載入仍停在乙。
- **WHEN** 使用者連續切換，先前頁面的背景工作較晚完成
- **THEN** 最後選擇的頁面與草稿保持正確，不被舊請求切回、覆蓋或錯誤停用
