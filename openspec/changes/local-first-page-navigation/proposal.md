# Proposal

## Why

已下載頁面每次切換仍先等待版本檢查與頁面資訊請求，正文因此反覆顯示「正在準備你的寫作空間」。將本機內容顯示與雲端驗證分開，讓使用者立即繼續寫作，同時保留權限、草稿與還原版本隔離。

## What Changes

- 已下載頁面優先顯示本機標題與正文，允許先編輯及保存本機；背景驗證成功後才連線同步。
- 頁面資訊與程式版本查詢不阻塞已下載頁面的站內切換；發現新版後先保存當下草稿再載入最新目標頁。
- 驗證遇到登入失效、刪除、權限或內容版本變更時，停止編輯／同步並保留包含驗證期間輸入的草稿。
- 未下載、快取損毀或擁有者不符時不使用該快取，維持完整雲端載入流程。
- 以延遲請求、快速切換、背景失敗與新 context 讀取驗證行為；不更動線上限定的標題、階層與圖片操作。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `workspace-usability`：強化已下載頁面本機優先開啟，調整新版本檢查時機，新增背景驗證與草稿保護情境。

## Impact

影響 `src/client/main.tsx`、`api.ts`、`editor.tsx`、`page-cache.ts` 的載入與生命週期協調，以及 `tests/e2e/local-first.spec.ts`、`spa-navigation.spec.ts` 的自動驗收。沿用現有本機儲存、Yjs 與伺服器授權機制，不新增服務或改動伺服器公開 API。本 change 目前只建立規劃文件。
