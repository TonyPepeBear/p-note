## MODIFIED Requirements

### Requirement: 遠端工具與筆記操作

plugin SHALL 透過公開 HTTPS 遠端 MCP 提供列表、搜尋、頁面資訊、建立、改名、移動、日期日記、月份日記、頁面區塊正文讀寫及同步區塊正文讀寫共 12 個工具。工具 MUST 限於授權帳號並拒絕未知工具與無效參數，不要求使用者電腦執行本機程式。同步正文更新 MUST 沿用 ETag，頁面正文可選擇展開同步引用但不可透過頁面更新間接改寫同步正文。

#### Scenario: 工具發現與讀寫

- **WHEN** 已授權的雲端相容 MCP client 連接服務並呼叫工具
- **THEN** 可完成握手與工具發現，12 個工具的結果與網站一致，日記同日唯一且頁面及同步區塊正文雙向同步
- **自動化驗證**: `PLUGIN-01`；Playwright 真實 HTTP MCP 請求，斷言 12 個工具列表、筆記操作、日記唯一性、同步引用展開、同步正文 ETag 往返及網站正文。
