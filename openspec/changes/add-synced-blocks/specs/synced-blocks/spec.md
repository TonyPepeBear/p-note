## ADDED Requirements

### Requirement: 建立與引用同步區塊

系統 SHALL 允許擁有者將選取的一個或多個既有區塊轉成同步區塊，或由 `/` 選單建立空同步區塊。同步引用 MUST 指向同一份正文，同頁可重複引用；同步正文 MUST 只允許現有支援區塊且禁止巢狀同步區塊。

#### Scenario: SB-01 選取轉換與空白建立
- **自動化驗證**: `SB-01`；Playwright 以單區塊、多區塊選取及 `/` 選單建立，斷言原始順序／格式保留、原位置變成具 ID 的同步引用、空白建立有可編輯正文且重開保留。
- **WHEN** 連線中的擁有者轉換選取內容或從 `/` 選單新增同步區塊
- **THEN** 系統建立一份新的同步正文，並在來源位置插入它的引用

#### Scenario: SB-02 複製貼上引用
- **自動化驗證**: `SB-02`；Playwright 複製同步區塊並貼到另一筆記、日記與同頁兩次，斷言各引用 ID 相同、同步正文只有一份，任一處修改會反映至所有引用。
- **WHEN** 使用者將同步區塊複製貼到可編輯頁面
- **THEN** 系統新增指向原同步 ID 的引用，不複製出獨立正文

#### Scenario: SB-03 區塊類型及禁止巢狀
- **自動化驗證**: `SB-03`；Workers 與 Playwright 往返段落、標題、清單、待辦、引用、分隔線、格式、圖片、程式碼及 `[[` 連結，斷言正文保留；嘗試 UI 貼入及 API 寫入同步引用到同步正文，斷言拒絕且原正文不變。
- **WHEN** 使用者編輯同步正文或嘗試插入另一個同步引用
- **THEN** 既有支援類型可正常使用，巢狀同步引用無法建立且不會形成循環

### Requirement: 即時同步與持久保存

系統 SHALL 沿用 Yjs 合併與持久保存回執，在任一引用處編輯時更新其他頁面及裝置。頁面 MUST 聚合頁面正文與全部引用同步文件的保存狀態；任何一份未完成保存都不能顯示已儲存。載入與保存錯誤 MUST 限於該同步區塊，保留原內容且其他正文仍可編輯。

#### Scenario: SB-04 跨頁及跨裝置共同編輯
- **自動化驗證**: `SB-04`；Workers 與 Playwright 建立實際雙端 Yjs／WebSocket 及隔離瀏覽器 context，在不同引用頁並行插入，斷言雙方合併、同頁重複引用同步、重開及 DO 重啟後正文一致。
- **WHEN** 多個引用端同時編輯同一個同步區塊
- **THEN** 更新依現有 Yjs 規則合併，所有有效引用即時取得相同結果

#### Scenario: SB-05 保存回執聚合
- **自動化驗證**: `SB-05`；Workers 與 Playwright 延遲／失敗單一同步 DO 持久寫入，斷言未持久化不確認也不廣播、頁面即使自身已保存仍不顯示已儲存，全部文件持久保存後才顯示已儲存。
- **WHEN** 頁面或任一引用同步區塊尚未收到持久保存確認
- **THEN** 頁面保存狀態持續標示待保存或失敗，不能提早宣告已儲存

#### Scenario: SB-06 區塊錯誤隔離與重試
- **自動化驗證**: `SB-06`；Playwright 對一個引用注入載入、雲端及本機保存故障，斷言該外框顯示錯誤及重試、原文／草稿保留不被空內容覆蓋、其他同步區塊及一般正文可繼續編輯，解除故障後保存原草稿。
- **WHEN** 單一同步引用無法載入或保存
- **THEN** 錯誤只呈現在該區塊，原內容保留且頁面其他部分不被阻擋

### Requirement: 離線同步內容

系統 SHALL 在開啟頁面時快取其引用正文，已下載正文可離線編輯並在重連後合併。尚未下載同步正文離線時 MUST 顯示「離線無法載入」且不可編輯，離線 MUST 不得建立新的同步區塊。

#### Scenario: SB-07 已下載內容離線保存與合併
- **自動化驗證**: `SB-07`；Playwright 開啟引用頁後關閉網路、修改同步正文並刷新，斷言草稿保留，與另一個 context 的連線修改重連合併，所有引用與再次重開一致。
- **WHEN** 曾下載的同步區塊在離線期間修改後重新連線
- **THEN** 本機內容可編輯及保存，重連沿用 Yjs 合併且不丟失任一端更新

#### Scenario: SB-08 未下載內容與離線建立
- **自動化驗證**: `SB-08`；Playwright 只保留頁面快取並移除該同步內容快取後離線開啟，斷言「離線無法載入」、無可寫空編輯器、一般正文可編輯，建立與轉換入口停用且不新增同步正文；重連後取得原文。
- **WHEN** 離線開啟未下載的同步區塊或嘗試建立新同步區塊
- **THEN** 未下載引用明確不可編輯，所有新建同步區塊操作需要連線

### Requirement: 解除同步與引用生命週期

系統 SHALL 讓單一引用解除同步為當下內容的一般區塊。移除引用 MUST 只移除該頁引用；最後引用移除後仍保留同步正文，不永久刪除、不自動清理，並可由引用管理或垃圾桶恢復。引用頁面移入垃圾桶或還原 MUST 不改變同步區塊自身狀態。

#### Scenario: SB-09 單一引用解除同步
- **自動化驗證**: `SB-09`；Playwright 對多個引用之一解除同步，斷言原位展開當下完整區塊與格式、該引用 ID 移除，後續同步正文與一般正文互不影響，其他引用繼續同步。
- **WHEN** 使用者解除某個引用的同步
- **THEN** 只將該引用轉成一般區塊，保留當下內容且不影響其他引用

#### Scenario: SB-10 刪除引用與孤立內容恢復
- **自動化驗證**: `SB-10`；Workers 與 Playwright 逐一刪除所有引用，斷言頁面引用移除而同步原文仍存在、清理及保留任務不刪除原文，管理入口能將同一 ID 與正文恢復到頁面。
- **WHEN** 同步區塊的最後一個引用被移除後再次恢復
- **THEN** 同步區塊保留原 ID 及正文，可重新建立引用

#### Scenario: SB-11 引用頁面垃圾桶及還原
- **自動化驗證**: `SB-11`；Workers 與 Playwright 刪除／還原引用頁及其上層，斷言只改變該頁引用可見性、同步正文和其他頁引用仍保留，還原後重新列入引用。
- **WHEN** 引用頁面被移入垃圾桶或還原
- **THEN** 同步區塊本身不跟著刪除或還原，其他引用不受影響

### Requirement: 引用管理與內容索引

系統 SHALL 顯示同步區塊在 N 個可見頁面使用的數量及可點擊清單，同頁多次引用只計一頁，垃圾桶頁面不列入。搜尋 MUST 將同步文字投影到每個可見引用頁；同步內的筆記連結 MUST 在反向連結呈現每個引用來源並依頁面 ID 去重。

#### Scenario: SB-12 引用數與跳轉
- **自動化驗證**: `SB-12`；Workers 與 Playwright 建立同頁重複及跨頁引用，斷言「已在 N 個頁面使用」依可見頁面 ID 計算、清單顯示當下標題並可跳轉，垃圾桶及不可見來源不出現。
- **WHEN** 使用者查看同步區塊的引用清單
- **THEN** 顯示可見來源頁面與正確去重數量，點擊可到達對應頁面

#### Scenario: SB-13 搜尋投影
- **自動化驗證**: `SB-13`；Workers 寫入及更新同步文字，斷言搜尋包含每個可見引用頁各一次，移除引用或垃圾桶後排除、還原後恢復，其他擁有者及舊世代永不出現。
- **WHEN** 搜尋文字只出現在同步區塊正文
- **THEN** 每個可見引用頁都能被搜到，結果不包含垃圾桶或無權限頁面

#### Scenario: SB-14 同步筆記連結反向投影
- **自動化驗證**: `SB-14`；Workers 在同步正文建立重複 `[[` 連結、同頁重複引用及一般正文重複連結，斷言反向來源依頁面 ID 去重、每個可見引用頁都有來源，移除連結／引用或垃圾桶後正確更新。
- **WHEN** 同步正文含有指向另一頁的筆記連結
- **THEN** 目標反向清單列出每個可見引用頁一次

### Requirement: 同步區塊私人存取與世代

系統 MUST 對同步區塊所有讀取、更新與同步連線驗證擁有者、現行世代及有效引用權限，拒絕未登入、跨擁有者、舊世代及已刪除或無權限引用的連線與寫入。

#### Scenario: SB-15 授權與無效同步連線拒絕
- **自動化驗證**: `SB-15`；Workers 以未登入、其他擁有者、過期／撤銷 API／MCP 身分、舊世代、垃圾桶頁及已移除引用嘗試 HTTP 與 WebSocket；斷言讀寫拒絕、既有失效連線更新無法持久化或廣播，合法引用仍可使用。
- **WHEN** 存取者或引用不符合目前同步區塊授權條件
- **THEN** 系統拒絕存取，不洩漏正文或把無效更新合併進目前文件

### Requirement: 備份匯出與覆蓋還原

系統 SHALL 在 90 天備份與 ZIP 匯出保留同步原文和引用關係，可讀匯出在引用位置展開內容並標註同步 ID。覆蓋還原 MUST 將頁面與同步區塊一起切換世代、隔離舊裝置狀態，並相容尚無同步區塊的舊備份。

#### Scenario: SB-16 完整備份與可讀匯出
- **自動化驗證**: `SB-16`；Workers 建立每日及手動備份、下載 ZIP 與可讀格式，斷言同步 Yjs 原文／metadata／引用關係／圖片完整且校驗正確、重複引用不複製原始文件、可讀引用展開正文並含同步 ID，90 天保留邊界沿用既有契約。
- **WHEN** 系統備份或使用者匯出含同步引用的資料
- **THEN** 原始格式保留同一內容的引用關係，可讀格式於各引用位置顯示實際內容及同步 ID

#### Scenario: SB-17 還原世代與舊備份相容
- **自動化驗證**: `SB-17`；Workers 在保留舊頁面與同步連線後覆蓋還原，斷言共同切換新世代、原文／引用／搜尋與反向索引一致、舊更新拒絕；還原無同步欄位的舊 ZIP 及損壞同步文件，斷言前者成功且後者保留原世代不部分套用。
- **WHEN** 覆蓋還原含同步區塊或舊版備份
- **THEN** 新世代頁面與同步內容一致，舊裝置不能自動合併回來，無同步資料的舊備份仍能還原

### Requirement: JSON API 與 MCP 同步正文

頁面 JSON 正文 SHALL 以引用節點與同步 ID 表示並可選擇展開。系統 SHALL 提供單一同步正文讀寫與 MCP 對應工具，更新 MUST 沿用 ETag 防止覆寫。頁面正文更新 MUST 只能增刪有效引用，不得間接改寫同步正文。

#### Scenario: SB-18 頁面 JSON 引用與選擇展開
- **自動化驗證**: `SB-18`；Workers 讀取含重複引用的頁面 JSON 及展開選項，斷言預設只含引用節點與同步 ID，展開提供對應當下原文且不改寫儲存的頁面，無權限或無法載入內容不以空正文冒充。
- **WHEN** API 或 MCP 讀取頁面正文並選擇是否展開同步內容
- **THEN** 預設保留引用識別，明確要求時可取得同一同步內容的唯讀展開

#### Scenario: SB-19 單一正文 ETag 與 MCP
- **自動化驗證**: `SB-19`；Workers 透過 API 與 MCP 讀寫同一同步正文，斷言正確 ETag 更新成功並廣播、舊／缺少 If-Match 拒絕且原文不變、唯讀 scope 不可寫、最新 ETag 可再次更新。
- **WHEN** API 或 MCP 更新單一同步區塊正文
- **THEN** 必須驗證身分與版本，避免覆蓋另一個引用端較新的修改

#### Scenario: SB-20 頁面更新僅增刪引用
- **自動化驗證**: `SB-20`；Workers 以頁面 API／MCP 增刪既有同步引用，斷言頁面與引用索引更新而同步原文不變；夾帶內嵌正文、未知／跨擁有者同步 ID 及巢狀引用時拒絕且兩份文件保持不變。
- **WHEN** 使用者透過頁面正文介面新增或移除同步引用
- **THEN** 只更新引用關係，不能藉此改變同步內容或加入無效引用

### Requirement: 手機鍵盤與中文輸入

同步區塊 SHALL 具明確外框，手機建立、解除同步與查看引用可直接點擊，鍵盤可以操作。跨文件同步 MUST 不打斷中文輸入法正在選字的內容。

#### Scenario: SB-21 可直接點擊與鍵盤操作的外框
- **自動化驗證**: `SB-21`；Playwright 在 Chromium 桌面／手機與 WebKit 手機，以 tap 或 Tab／Enter 操作建立、解除同步及引用清單，斷言按鈕不需 hover、外框具有可見 border、焦點合理、窄 viewport 不橫向溢出。
- **WHEN** 使用者以手機觸控或鍵盤管理同步區塊
- **THEN** 必要操作皆可直接使用，使用者可清楚辨識同步區塊範圍

#### Scenario: SB-22 中文選字與跨文件同步
- **自動化驗證**: `SB-22`；Playwright 以 composition／beforeinput／input fixture 在同步正文選字期間讓另一頁與另一同步區塊接收更新，斷言活動編輯器節點、選字文字及游標不被重建或重置，compositionend 後正文保存且雙端一致；不宣稱操作實際 OS 輸入法。
- **WHEN** 使用者中文輸入尚未結束時收到跨文件更新
- **THEN** 目前選字內容與焦點持續保留，完成選字後正常同步保存
