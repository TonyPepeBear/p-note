# Why

筆記與日記目前只能複製各自獨立的正文，重複資訊無法共同編輯。新增擁有者私有的同步區塊，讓同一內容在多個頁面出現，並沿用既有即時協作、離線保存、備份與還原隔離規則。

# What Changes

- 將選取的單一或多個區塊轉成同步區塊，或從 `/` 選單新增空區塊；複製貼上建立同一內容的引用，同頁可重複引用，禁止巢狀同步區塊。
- 每個同步區塊使用獨立同步文件，各引用共同編輯；頁面保存狀態聚合所有引用文件，失敗只影響該區塊。
- 已下載引用內容可離線編輯與重連合併；未下載內容顯示「離線無法載入」，離線禁止建立同步區塊。
- 支援單一引用解除同步、移除引用、引用頁面清單；孤立內容保留，可從引用清單或垃圾桶恢復。
- 搜尋及反向連結把同步內容投影到每個可見引用頁面，依頁面 ID 去重且排除垃圾桶。
- 所有讀寫與同步連線驗證擁有者、現行世代及引用有效性；備份、ZIP、可讀匯出、覆蓋還原涵蓋同步內容和引用關係。
- JSON API 可讀引用與選擇展開，單一區塊 API／MCP 沿用 ETag；頁面正文更新只能增刪引用。
- 提供手機可直接點擊與鍵盤操作的建立、解除同步及引用管理，以及不打斷中文選字的跨文件同步。

# Capabilities

## New Capabilities

- `synced-blocks`：私有同步區塊的建立、共同編輯、保存、離線、引用管理、索引、備份還原及 API／MCP。

## Modified Capabilities

- `codex-plugin`：遠端工具由 11 個擴充為 13 個，加入單一同步區塊正文的讀寫與版本保護。

# Impact

涉及 BlockNote 編輯器、Yjs 文件與本機快取、D1 引用索引、Durable Object 同步驗證、搜尋與反向連結、備份 ZIP／還原、內容 API／MCP、Workers 與 Playwright 自動化驗證。
