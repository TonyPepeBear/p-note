# Design

## Context

目前登入頁在視窗左上僅有標題、輸入與原生按鈕；工作區由導覽表單、頁面設定及編輯工具堆疊。全域 `button`、`main` 與 `h1` CSS 也覆蓋元件庫。既有 BlockNote 支援已安裝的 Mantine 9.7.2，延續 React／BlockNote／Yjs 與資料保護流程。

## Goals / Non-Goals

**Goals:** 讓寫作成為第一層，管理功能進入獨立面板；桌面與手機一致的工作流程；以真實元件操作、幾何斷言和截圖檢查整體呈現。

**Non-Goals:** 不增添協作權限、資料模型、行銷頁或裝飾圖片；不以重新建立空白資料庫替代資料相容性。

## Decisions

- MantineProvider 與一致 theme；直接宣告 `@mantine/core`／`@mantine/hooks` 9.7.2，BlockNote 共用 Provider。使用成熟圖示套件，圖示搭配中文文字或可讀標籤。保留現有編輯器，避免重寫正文／同步。
- 視覺：霧白底、暖灰側欄、深墨文字與青綠主色；標題、正文與中性輔助文字有固定層次；內容最大閱讀寬度約 800px。按鈕、輸入與卡片使用框架樣式；刪除全域原生元素覆寫，CSS 僅處理產品版面。
- 工作區採 AppShell／手機 Drawer。側欄分為「今天／日記／筆記」與底部「垃圾桶／備份設定」，搜尋固定在頂部。文件顯示路徑、類型、標題、正文與保存狀態。
- 日期、月份與搜尋不常駐占用側欄；使用 Modal 與結果列表。頁面標題、移動與垃圾桶從頁面操作進入；Modal 關閉返回原觸發點。轉頁先保存本機草稿。
- 圖片上傳與格式說明進入獨立 Modal，重試保留檔案；區塊工具可鍵盤／觸控使用。保留測試識別但不在產品中展示測試者或原型技術資訊。
- 備份用卡片列出時間、狀態、下載與還原；空列表有下一步說明，覆蓋還原仍需勾選確認與重試識別。
- Playwright 在既有三種瀏覽器測試新流程、彈窗焦點、至少 44px 主操作、375px 版面、首屏正文與無水平溢出；保存多畫面截圖供本次開發檢查，不建立人工驗收門檻。

## Risks / Trade-offs

- [調整入口造成舊測試找不到控制項] → 以新使用者工作流程更新 helper，保持原行為斷言；完整功能回歸。
- [Modal／Drawer 遮住操作或焦點失去] → 斷言 Escape、焦點返回、選擇後關閉與行動版不溢出。
- [全域樣式破壞 BlockNote] → 只對產品容器命名 class，檢查程式碼、工具列、圖片與中文字輸入。
- [備份切換或離線編輯遺失資料] → 沿用 saveDraft、session、IndexedDB 與已驗證還原流程。
