## MODIFIED Requirements

### Requirement: 一致編輯與備份呈現

系統 SHALL 將正文、資料庫、備份、API key 及其浮層全部套用共用的字級、間距、色彩與狀態規則。資料庫 SHALL 使用可鍵盤操作的檢視分頁與相鄰工具列；主要功能 MUST 可完成多步操作、可鍵盤操作且適合手機觸控。備份還原進行中或中斷待重試時，瀏覽器返回 MUST 保留目前設定與網址、隱藏文件並沿用原還原請求；設定期間的全域錯誤 MUST 在備份及 API key 頁保持可見且可關閉。

#### Scenario: 編輯工具與私人圖片
- **自動化驗證**: `UI-05`；Playwright 斷言圖片及區塊操作、保存失敗重試、資料庫檢視 tabs 的選中與鍵盤切換、搜尋清除，以及資料庫新增筆記／編輯／返回後內容與列保留。
- **WHEN** 使用者編輯正文、插入圖片，或在資料庫切換檢視並開啟或新增筆記
- **THEN** 畫布以內容為主，工具與 properties 緊鄰其內容；表格僅在自身容器捲動，檢視切換與編輯往返不遺失資料

#### Scenario: 備份空狀態與還原確認
- **自動化驗證**: `UI-06`；Playwright 斷言設定頁保留導覽、備份／API key 切換後返回原文件與內容、設定中選擇其他筆記、備份建立／下載／還原確認，以及 API key 建立／撤銷流程；BACKUP-UI-LOCK-01 斷言還原執行中與中斷後的離頁入口及瀏覽器返回鎖定、原網址與備份保留及相同 request ID 重試；UI-06-ERROR 斷言備份及 API key 頁的側欄登出與今天儲存失敗提示可見、可關閉且設定保留；KEY-03 斷言設定期間背景 401 後立即隱藏 key、離開設定、顯示重新登入並保留草稿。
- **WHEN** 使用者從文件進入備份或 API key 設定、切換設定、執行或重試還原，或設定期間登入失效
- **THEN** 正常設定操作保留導覽及原文件 context；還原執行中與中斷待重試時不能由返回、瀏覽器歷史導覽、側欄或登出入口離開流程，重試沿用原備份及 request ID；背景登入失效立即離開設定並隱藏 key，重新登入提示與保留草稿可見；設定期間側欄失敗仍顯示可關閉的全域錯誤；空資料、載入、錯誤與重試有一致呈現，備份覆蓋及 key 撤銷仍需清楚確認
