# Design

## Context

現有 React／Mantine／BlockNote 工作區已具備頁面樹、搜尋、日記、資料庫、離線編輯、備份與 API key。此次重做所有介面，直接以 Notion 的輕量導覽、無框文件與資料庫資訊層次為基準；共用元件和語義必須一致，不能只修改首頁。

## Goals / Non-Goals

**Goals:** 所有已存在的 UI 使用同一套視覺語言；桌面有足夠資料密度，手機可觸控；使用者能從寫作到設定或資料庫再回到工作內容，保留目前頁面與資料。

**Non-Goals:** 不新增多人協作、權限模型或 Notion 未存在於本產品的功能；不複製商標、品牌資產或虛構產品能力；不更換儲存與同步協定。

## Decisions

- 視覺 token：白色主畫布、約 `#F7F7F5` 側欄、`#37352F` 主要文字、可達 WCAG AA 的中性輔助文字、細灰分隔線。主要動作與焦點使用少量藍色；選中導覽採淺灰。移除正文卡片外框、背景裝飾與大範圍陰影。
- 桌面側欄約 240px，常用導覽列約 30–36px；頂部工具列約 45–52px。文件維持閱讀寬度，資料庫可使用更寬畫布。側欄收合後仍有可辨識、可鍵盤操作的恢復入口，收合不觸發換頁或清空草稿。
- 手機導覽改為 drawer，文件左右保留約 16–20px，主要觸控操作至少 44px；首屏上半部可開始書寫。寬表格僅在自身容器捲動，頁面不得水平溢出。
- 資料庫檢視改用可鍵盤操作的 tabs，搜尋及管理操作置於相鄰工具列。表格、清單、欄位、篩選與排序顯示維持緊密層次；新增與開啟筆記沿用目前頁面導覽及保存契約。
- 備份與 API key 設定放在共用工作區 shell 中，保留側欄、目前文件及返回入口；從設定選擇其他筆記必須離開設定並顯示該文件。開啟設定前仍使用既有草稿保存流程。
- 共用 shell 的還原狀態與登入狀態優先於一般導覽：還原執行中或中斷待重試時鎖定返回、側欄與登出等離頁入口，保留原備份及 request ID 重試；設定期間背景驗證收到 401 時立即卸載設定、隱藏完整 key、顯示重新登入並保留草稿。
- 浮層保留標題、欄位標籤、Escape、焦點返回與危險動作確認。載入、空資料、搜尋零結果、錯誤、重試、離線與復原狀態採一致層次，不把內部技術資訊當成主要操作。
- 保留既有 accessible names 與 test IDs；真正的導覽語義變更（例如 select 改 tabs）同步更新測試，不為舊測試保留隱藏的假控制項。

## Coverage

登入／確認登入；桌機 shell／手機 drawer；頁面樹／breadcrumb／文件標題；搜尋／日記／頁面操作／刪除確認／垃圾桶；正文／工具列／區塊選單／圖片／保存與草稿復原；資料庫／檢視設定／欄位管理／欄位值；備份列表／覆蓋還原；API key 建立／顯示／複製／撤銷；全域載入、提示與錯誤。

## Validation

新增 `notion-redesign.spec.ts` 的多步操作驗證，配合既有 UI、UX、資料庫、備份、API key 與離線測試。Red／Green 僅由主代理集中使用同一套 E2E 服務執行；完成後執行三個 Playwright 專案、型別、建置與文件契約檢查。截圖以合成測試資料產生，沒有人工驗收門檻。

## Risks / Trade-offs

- 共用 shell 可能讓設定返回錯誤頁面：以切換設定、返回原文件及從側欄開啟另一筆記的流程斷言。
- 緊密桌面樣式可能使手機難以操作：分開斷言桌機密度、手機 44px 主要動作與 375px 無溢出。
- tabs 改動可能破壞檢視狀態：斷言切換後的資料、搜尋、重開與新增筆記往返，不只比對 class。
- 全站樣式可能影響 BlockNote、長標題或浮層：沿用既有功能回歸並檢查可見區域與焦點，禁止以隱藏失敗內容換取通過。
