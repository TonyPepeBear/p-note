# Proposal

## Why

現有介面雖已使用元件庫，仍以厚重卡片、過多說明與分離的設定頁呈現；側欄密度、文件畫布、資料庫檢視及管理面板沒有形成一致的工作區。使用者明確要求所有 UI 依 Notion 的版面與互動方式全面重做。

## What Changes

- 建立白色文件畫布、暖灰緊湊側欄、單色圖示及一致字級的視覺系統，套用至登入、確認登入、工作區、編輯器、資料庫、設定及所有浮層。
- 桌面側欄可收合與恢復，手機使用導覽抽屜；編輯、切換設定與返回文件均保留原文件及草稿。
- 資料庫以檢視分頁、精簡工具列、表格／清單及貼近內容的欄位呈現，保留搜尋、篩選、排序與欄位管理。
- 搜尋、日記、頁面操作、垃圾桶、圖片、區塊選單、備份、API key 與草稿復原採相同的視覺、鍵盤與狀態規則。
- 以多步使用者操作、版面幾何、無水平溢出、觸控尺寸及既有全功能回歸驗收。

## Capabilities

### Modified Capabilities

- `workspace-experience`：全面更新工作區與所有管理／編輯介面的呈現及操作一致性。

## Impact

修改前端 shell、導覽、樣式、登入、文件、資料庫與設定元件，以及相關 E2E 與驗收文件。沿用目前資料與 API 契約，正文同步、離線草稿、權限、備份及 API key 行為須維持可用。

實作與驗證完成後，合併前封存本 OpenSpec change 並同步主規格；合併後以 master workflow 的資料遷移與發布結果為交付依據，發布成功後結束。
