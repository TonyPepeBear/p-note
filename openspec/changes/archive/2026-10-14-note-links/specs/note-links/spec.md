## ADDED Requirements

### Requirement: 正文筆記連結

系統 SHALL 支援以 `[[` 搜尋筆記與日記標題並插入穩定頁面識別的連結；連結 MUST 沿用正文同步與保存保護。

#### Scenario: LINK-01 搜尋並插入筆記連結
- **自動化驗證**: `LINK-01`；Playwright 以實際鍵盤輸入 `[[` 搜尋中文、同名筆記與日記，斷言選擇後移除查詢字串、原生 link 的 href／文字正確、重開保留且點擊站內換頁。
- **WHEN** 使用者輸入 `[[` 並選擇搜尋結果
- **THEN** 正文插入所選頁面 ID 連結，鍵盤／觸控皆可操作，沒有結果時不建立不存在頁面

#### Scenario: LINK-04 離線修改與跨裝置同步
- **自動化驗證**: `LINK-04`；Playwright 斷言已下載頁面離線仍可插入快取目標連結、刷新保留，重連後第二個 context 收到同一 href，目標反向連結更新。
- **WHEN** 已下載正文離線修改後重連
- **THEN** 連結與正文一同保存及同步，反向連結於雲端同步後更新，離線清單明確提示需要連線

#### Scenario: LINK-06 查詢失敗與保存保護
- **自動化驗證**: `LINK-06`；Playwright 注入搜尋／反向查詢及本機保存失敗，斷言可重試、不冒充無引用、正文保留、導航失敗仍停在來源頁面；自動檢查手機寬度無溢出。
- **WHEN** 搜尋、清單查詢或導航前本機保存失敗
- **THEN** 顯示失敗狀態或保留原查詢與正文，不把失敗當成空清單，不丟失尚未保存內容

### Requirement: 私有反向連結

系統 SHALL 顯示引用目前頁面的可見來源頁面，依穩定 ID 去重；隱藏來源、其他擁有者及舊正文世代 MUST 不得出現在結果。

#### Scenario: LINK-02 反向索引增刪與去重
- **自動化驗證**: `LINK-02`；Workers 與 Playwright 寫入重複、巢狀與表格中的原生連結，斷言來源只出現一次、移除最後引用後消失、自我引用與外部網址不列入，點來源可返回。
- **WHEN** 正文新增或移除目標頁面連結並同步
- **THEN** 目標頁反向清單隨索引更新且沒有重複來源

#### Scenario: LINK-03 改名、垃圾桶與權限
- **自動化驗證**: `LINK-03`；Workers 與 Playwright 斷言目標改名後 ID 連結仍可開啟、來源改名顯示新標題、來源及上層垃圾桶排除／還原恢復，未登入、跨帳號、舊世代與不可見目標拒絕或排除。
- **WHEN** 引用雙方改名、移入垃圾桶、還原或失去存取權限
- **THEN** 連結不依賴名稱，反向清單只包含目前擁有者可見的來源；目標垃圾桶仍可由既有還原入口處理

#### Scenario: LINK-05 JSON API 與備份還原
- **自動化驗證**: `LINK-05`；Workers 透過 JSON API 寫入原生連結，斷言讀取保留 href、備份正文包含連結、覆蓋還原後從新世代重建反向索引並移除還原前引用。
- **WHEN** API 更新連結正文或覆蓋還原包含連結的備份
- **THEN** 連結格式往返保留，反向結果與恢復正文一致，不沿用舊世代索引
