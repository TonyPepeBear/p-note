# Proposal

## Why

筆記與日記目前無法從正文快速連結其他頁面，也看不到引用自己的筆記，難以串連相關知識。
需要建立不受改名影響的站內連結，並從頁面直接返回引用來源，同時維持私人存取及離線保存。

## What Changes

- 輸入 `[[` 搜尋頁面標題，透過鍵盤或觸控插入穩定頁面 ID 的站內連結。
- 點連結沿用保存草稿與站內換頁；目標改名不影響連結，垃圾桶沿用還原入口。
- 正文同步後產生去重的反向連結，僅顯示同擁有者、目前可見且同世代的來源。
- 正文連結沿用 Yjs、離線快取、JSON API 與完整備份；還原時重建反向索引。

## Capabilities

### New Capabilities

- `note-links`：筆記連結與反向連結。

### Modified Capabilities

無。

## Impact

修改編輯器、頁面工作區與同步搜尋索引；新增 D1 向前相容 migration、反向連結查詢及自動化驗收。不新增公開權限、未連結文字比對或圖譜。
