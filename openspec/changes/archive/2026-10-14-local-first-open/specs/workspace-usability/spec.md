# Spec Delta

## ADDED Requirements

### Requirement: 已下載頁面本機優先開啟

系統 SHALL 在開啟裝置已下載過的頁面時，取得頁面資訊後立即顯示本機內容並允許編輯，不得等待雲端同步完成；同步完成前 MUST 顯示同步中而非已儲存，完成後 SHALL 取得持久保存確認。尚未下載的頁面 MUST 等待雲端同步後才允許編輯。

#### Scenario: 雲端連線緩慢時開啟已下載頁面
- **自動化驗證**: `UX-21`；Playwright：先開啟並保存頁面使其下載，再讓同步 WebSocket 延後 3 秒才連到伺服器並重新整理，斷言 2 秒內顯示可編輯與原內容、雲端狀態為同步中且未出現重試按鈕；輸入文字後斷言最終顯示雲端已儲存，以新 context 開啟時伺服器已有該文字。
- **WHEN** 使用者在雲端連線緩慢時開啟曾開過的頁面
- **THEN** 立即可閱讀與編輯，同步在背景完成並保存

#### Scenario: 未下載頁面仍等待雲端
- **自動化驗證**: `UX-22`；Playwright：在沒有本機快取的新 context 中讓同步 WebSocket 延後 2.5 秒，開啟已有內容的頁面，斷言 1.5 秒時尚未顯示可編輯的編輯器，連線後顯示可編輯且內容完整。
- **WHEN** 使用者在新裝置開啟尚未下載的頁面
- **THEN** 等雲端內容到達後才顯示編輯器，不會先出現空白可編輯內容
