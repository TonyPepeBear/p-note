# Context

目前頁面以獨立 Yjs 文件協作，Durable Object 持久寫入後才回覆保存確認，本機 IndexedDB 保存已下載文件。同步區塊需要在不同頁面間共享正文，且不能削弱現行擁有者隔離、還原世代與離線資料保護。

# Goals / Non-Goals

同步區塊與頁面共同遵守既有保存與世代隔離契約；所有需求由 Workers 或瀏覽器斷言驗收。同步區塊只屬於單一擁有者，不新增共享筆記權限或巢狀同步文件。

# Decisions

- 頁面正文只保存 `syncedBlock` 引用節點與穩定同步區塊 ID，正文放在獨立 Yjs 文件。相同頁面可有多個引用節點，引用管理依來源頁面 ID 去重。
- 同步區塊 metadata 及頁面引用索引在 D1 保存，以擁有者與世代限制查詢。同步文件保留現有 DO 持久化、確認與 Yjs 合併流程；寫入或連線之前再次驗證擁有者、世代及引用頁有效性。
- 區塊正文使用既有支援的編輯器 schema（包含圖片、程式碼與原生筆記連結），但排除 `syncedBlock`。UI、JSON 驗證及同步寫入均拒絕巢狀引用。
- 編輯器以具明確外框的節點呈現獨立編輯器，建立、複製、解除同步與引用清單提供常駐可聚焦按鈕。複製貼上只傳遞引用 ID；解除同步先取得當下完整正文，再以一般區塊替換該引用。
- 頁面對每個唯一同步 ID 管理同步與 IndexedDB 資料，將頁面與全部同步文件的本機及雲端狀態聚合；任一未保存、失敗或未載入時不顯示已儲存。相同 ID 的重複引用不得重複連線或造成保存狀態錯置。
- 載入或保存失敗由該引用外框顯示可重試狀態；保留已知正文與本機草稿。頁面其他區塊維持可編輯，不以初始化空文件覆蓋失敗文件。未下載同步內容離線時不建立可寫空文件。
- 已開啟頁面下載所有引用正文，快取 key 包含擁有者、世代與文件種類；離線可改已快取內容，重連沿用 Yjs 合併。建立新同步區塊需要連線。
- 引用移除只改頁面正文／索引，最後引用移除仍保存同步 metadata 與正文；由管理入口重新插入孤立同步區塊。垃圾桶只改引用頁面的可見性，不連帶刪除或還原同步內容。
- 搜尋與反向連結即時根據目前可見引用頁面投影同步內容，更新同步正文後同步更新索引；同頁重複引用、直接與同步連結重複時依頁面 ID 去重。
- 備份 manifest 包含同步文件、metadata 與引用關係及校驗資訊；可讀匯出於引用位置展開並標註同步 ID。還原先驗證完整資料再啟用新世代，頁面與同步文件共同切換，舊 IndexedDB／WebSocket 不得回流。缺少同步欄位的舊 manifest 視為空集合。
- 內容 API 預設回傳引用節點，可明確要求展開唯讀投影；單一同步正文使用現有 ETag／If-Match 保護，MCP 對應讀寫工具沿用相同授權。頁面 API 只允許有效同步 ID，不接受內嵌同步正文寫入。
- 中文輸入期間保持該編輯器 instance 與選取，跨文件更新不重建活動編輯器；以 composition／beforeinput／input fixture 驗證選字文字、游標及最終雙端一致。

# Risks / Trade-offs

- 單頁引用多份文件增加連線與保存聚合成本：同頁同 ID 共用文件生命週期，導航後解除訂閱，測試重複引用及慢保存。
- D1 索引與 DO 保存可能中斷：索引只反映成功保存正文；故障測試驗證重試可恢復且不可顯示空內容。
- 還原與舊裝置並行可能帶回舊資料：所有讀寫與同步入口都檢查世代，測試保留舊連線和舊本機快取後切換。
- 瀏覽器手機模擬與合成 composition 不代表實際操作 OS 鍵盤；保留現有自動化範圍，不新增人工驗收門檻。

# Validation Plan

`SB-01`～`SB-22` 的工具、輸入及斷言以 [spec](specs/synced-blocks/spec.md) 為準。TDD 先執行相關 Chromium 桌面與 Workers 案例取得有效 Red，再以相同案例完成 Green／Refactor；最終執行三瀏覽器相關功能驗收、型別／建置、OpenSpec 嚴格驗證與 `--synced-blocks` 覆蓋檢查。未執行、skip、失敗、缺少必要層級與瀏覽器都不算覆蓋。
