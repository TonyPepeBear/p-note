# Design

## Context

Navigation 目前以同一個 Modal 編輯當前頁面資訊。現有 Mantine Menu 已用於區塊操作，可直接沿用。

## Goals / Non-Goals

提供一致頁面選單並明確分離操作目標與目前文件；保留既有操作，不新增複製、分享或權限管理。

## Decisions

- 右上角及側欄共用選單內容，以 Mantine Menu 處理鍵盤、Escape、外部點擊、焦點及邊界定位。側欄右鍵在游標位置開啟同一選單；手機維持可觸控「⋯」。不用自行實作選單或新增套件。
- 選單只顯示動作；重新命名、移動與刪除分別使用既有 Modal。動作目標保存為獨立頁面資料，表單與 API 都引用目標 ID。
- 修改其他頁面後更新樹；影響目前頁面祖先時更新路徑；刪除目前頁面或其祖先時回到今天，刪除其他頁面維持正文。移動選項排除目標及其後代。
- sidebar 的連結與選單按鈕為並列元件，避免巢狀互動控制項。還原鎖定時禁止按鈕及右鍵入口。
- 整合主線新增的版本歷史與我的圖片；目前頁面的版本歷史入口移至動作列表，沿用原本的單頁歷史與鎖定流程。

## Risks / Trade-offs

- 手機抽屜與選單焦點互相影響 → 選擇表單後關閉抽屜，取消返回有效觸發點；跨瀏覽器 E2E 驗證。
- 選單選到其他頁面卻誤改目前頁 → E2E 斷言目標 API 結果、目前 URL／正文保留及刪除確認目標。

## Migration Plan

無資料遷移；完成驗證及規格封存後合併至 master，由現有 Actions 發布。
