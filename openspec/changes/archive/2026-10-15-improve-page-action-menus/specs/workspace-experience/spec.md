# Spec Delta

## MODIFIED Requirements

### Requirement: 管理入口與清楚操作範圍

系統 SHALL 將搜尋、日記、頁面操作、垃圾桶、備份及 API key 放在一致且有名稱的介面；右上角與側欄每個頁面的「⋯」SHALL 顯示一致的動作列表；側欄右鍵 MUST 開啟該頁選單且不切換正文。選單 MUST 支援鍵盤、Escape、外部點擊關閉、有效焦點返回及手機觸控；還原鎖定時 MUST 禁止選單操作。重新命名、移動及刪除確認 MUST 明確操作選定頁面，修改其他頁面不得誤改目前文件，移動選項 MUST 排除目標及後代。設定頁 SHALL 保留工作區導覽與原文件 context。關閉浮層或返回文件 MUST 保留草稿與有效焦點；從設定選擇其他頁面 MUST 正確開啟所選文件。備份還原執行中或中斷待重試時 MUST 鎖定會離開還原流程的入口，並保留原備份及原 request ID。設定期間若背景驗證收到 401，系統 MUST 離開設定、立即隱藏已顯示的 API key、顯示重新登入介面並保留文件草稿。

#### Scenario: 搜尋與日記回顧面板
- **自動化驗證**: `UI-03`；Playwright 斷言搜尋／日記面板、結果與空狀態、Escape 焦點返回、選擇結果後開啟原頁，以及手機無重疊抽屜。
- **WHEN** 使用者搜尋筆記、選擇日記日期或月份，或取消面板
- **THEN** 輸入、結果、載入與錯誤層次清楚；選擇後返回文件，取消不改變正文且焦點返回可操作位置

#### Scenario: 頁面操作與垃圾桶
- **自動化驗證**: `UI-04`；Playwright 斷言重新命名／階層、長標題不溢出、右上角呈現列表且無頁面操作彈窗、側欄點擊及右鍵不換頁、選單鍵盤／Escape／外部關閉與手機觸控、其他頁面改名／新增子頁／新增子資料庫／移動及排除後代、失敗可重試、刪除確認目標、取消保留及垃圾桶還原回饋。
- **WHEN** 使用者由右上角、側欄「⋯」或側欄右鍵開啟動作列表，修改所選頁面資訊、移動頁面或管理垃圾桶
- **THEN** 先呈現精簡動作列表，選擇重新命名或移動後才開啟對應表單；開啟選單及修改其他頁面保留目前正文，危險動作說明所選目標與可還原方式，取消不刪除，完成與失敗有可辨識回饋；刪除目前頁面或祖先時安全返回今天
