# Proposal

## Why

目前已發布介面以原生表單堆疊功能，缺乏資訊層次、清楚入口與一致視覺，使用者無法理解或舒適使用。全面重做登入、工作區、日記、搜尋、頁面操作與備份介面，並以完整操作和版面斷言驗收。

## What Changes

- 使用 Mantine 重建整體介面，統一字級、間距、色彩、圖示、載入與錯誤狀態。
- 桌面固定側欄與寬敞文件區；手機抽屜導覽，正文直接可見。
- 日期／月份、搜尋、垃圾桶、頁面設定與圖片上傳各有明確的對話框入口。
- 區塊工具收斂至工具列，保存狀態清楚顯示，危險操作確認其影響。
- 重做備份列表、空狀態與還原確認；保留同步、離線草稿、權限與備份還原行為。
- 新增自動版面／焦點／工作流程測試與桌面手機截圖，完成後自動提交。

## Capabilities

### New Capabilities

- `workspace-experience`：可理解、可操作且一致的響應式介面與視覺層次。

### Modified Capabilities

無；第一版功能契約仍然適用，操作入口改以新工作流程呈現。

## Impact

前端登入、導覽、編輯器外框、圖片與備份設定；直接依賴 Mantine 與圖示套件，更新 E2E 操作方式。後端資料格式、既有筆記與登入權限不變。
