## MODIFIED Requirements

### Requirement: 清楚登入與寫作工作區

系統 SHALL 以 Notion 式的中性色、精簡導覽及白色無框文件作為全站設計基準；登入、確認登入、桌面及手機工作區 MUST 使用一致字級與控制項。桌面側欄 SHALL 支援收合與恢復，且不改變目前文件或已輸入內容；手機 SHALL 提供可觸控導覽而不壓縮正文。

#### Scenario: 登入頁與確認流程
- **自動化驗證**: `UI-01`；Playwright 檢查登入用途、Email、唯一主要登入動作、寄送與確認狀態、手機主要操作至少 44px 及無水平溢出。
- **WHEN** 未登入使用者開啟網站、寄送登入連結並進入確認頁
- **THEN** 各步驟以一致的精簡版面呈現目前狀態及下一步，錯誤保留可重試入口

#### Scenario: 正文優先的響應式工作區
- **自動化驗證**: `UI-02`；Playwright 斷言中性緊湊側欄、白色無框正文、收合與恢復後內容保留、375px 無溢出、手機 44px 主操作及新增後繼續編輯。
- **WHEN** 使用者在桌面收合與恢復導覽，或在手機使用導覽切換及新增筆記
- **THEN** 目前頁面與正文保持可用；桌機導覽緊湊且文件有閱讀空間，手機關閉抽屜後可立即編輯，管理介面不得把正文擠出首屏

### Requirement: 管理入口與清楚操作範圍

系統 SHALL 將搜尋、日記、頁面操作、垃圾桶、備份及 API key 放在一致且有名稱的介面；設定頁 SHALL 保留工作區導覽與原文件 context。關閉浮層或返回文件 MUST 保留草稿與有效焦點；從設定選擇其他頁面 MUST 正確開啟所選文件。

#### Scenario: 搜尋與日記回顧面板
- **自動化驗證**: `UI-03`；Playwright 斷言搜尋／日記面板、結果與空狀態、Escape 焦點返回、選擇結果後開啟原頁，以及手機無重疊抽屜。
- **WHEN** 使用者搜尋筆記、選擇日記日期或月份，或取消面板
- **THEN** 輸入、結果、載入與錯誤層次清楚；選擇後返回文件，取消不改變正文且焦點返回可操作位置

#### Scenario: 頁面操作與垃圾桶
- **自動化驗證**: `UI-04`；Playwright 斷言重新命名／階層、長標題不溢出、刪除確認目標、取消保留及垃圾桶還原回饋。
- **WHEN** 使用者修改頁面資訊、移動頁面或管理垃圾桶
- **THEN** 操作以緊湊表單與清楚標籤呈現，危險動作說明目標與可還原方式，完成與失敗有可辨識回饋

### Requirement: 一致編輯與備份呈現

系統 SHALL 將正文、資料庫、備份、API key 及其浮層全部套用共用的字級、間距、色彩與狀態規則。資料庫 SHALL 使用可鍵盤操作的檢視分頁與相鄰工具列；主要功能 MUST 可完成多步操作、可鍵盤操作且適合手機觸控。

#### Scenario: 編輯工具與私人圖片
- **自動化驗證**: `UI-05`；Playwright 斷言圖片及區塊操作、保存失敗重試、資料庫檢視 tabs 的選中與鍵盤切換、搜尋清除，以及資料庫新增筆記／編輯／返回後內容與列保留。
- **WHEN** 使用者編輯正文、插入圖片，或在資料庫切換檢視並開啟或新增筆記
- **THEN** 畫布以內容為主，工具與 properties 緊鄰其內容；表格僅在自身容器捲動，檢視切換與編輯往返不遺失資料

#### Scenario: 備份空狀態與還原確認
- **自動化驗證**: `UI-06`；Playwright 斷言設定頁保留導覽、備份／API key 切換後返回原文件與內容、設定中選擇其他筆記、備份建立／下載／還原確認，以及 API key 建立／撤銷流程。
- **WHEN** 使用者從文件進入備份或 API key 設定、切換設定或返回工作內容
- **THEN** 工作區導覽及原文件 context 保留；空資料、載入、錯誤與重試有一致呈現，備份覆蓋及 key 撤銷仍需清楚確認

### Requirement: 一致且可讀的互動色

系統 SHALL 在淺色工作區使用柔和中性的互動底色；目前項目、主操作及危險操作 MUST 保留可辨識語意。停用元件 MUST 不呈現可操作的 hover，鍵盤焦點 MUST 可見；觸控裝置 MUST 不留下黏住的滑鼠 hover。

#### Scenario: 中性操作與主操作 hover
- **自動化驗證**: `UI-07`；Playwright 斷言登入、工具列、備份與設定 hover 背景維持淺色、中性底色一致、hover 與預設不同、文字對比至少 4.5:1，主操作保留白字與可讀性。
- **WHEN** 滑鼠移至中性操作或主操作
- **THEN** 中性操作顯示柔和淺底、文字清楚；主操作維持全站一致的強調色與 hover 回饋

#### Scenario: 側欄選取與互動狀態
- **自動化驗證**: `UI-08`；Playwright 斷言未選取與選取項目 hover 均有回饋、aria-current 選取標記與文字對比保留；觸控操作後未選取項目不殘留 hover。
- **WHEN** 使用者以滑鼠或觸控操作側欄
- **THEN** 未選取、選取與 hover 可區分，目前頁面持續標記

#### Scenario: 選單與編輯器互動一致
- **自動化驗證**: `UI-09`；Playwright 斷言區塊選單及 BlockNote 工具 hover 使用一致淺色背景、文字對比至少 4.5:1；危險操作維持紅色及可讀性。
- **WHEN** 使用者操作區塊選單或編輯器工具
- **THEN** 互動色與工作區一致，刪除類動作保留紅色語意

#### Scenario: 停用與鍵盤焦點
- **自動化驗證**: `UI-10`；Playwright 斷言停用上傳與還原操作在 pointer 移入後背景不變、保持 disabled、確認啟用後還原按鈕對比至少 4.5:1；鍵盤 Tab 焦點有可見 outline 且能操作面板。
- **WHEN** 元件尚不可操作或使用者以鍵盤移動焦點
- **THEN** 停用項目無 hover 回饋且不可執行；可用元件保留可見鍵盤焦點
