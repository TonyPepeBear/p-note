# Spec Delta

## ADDED Requirements

### Requirement: 資料庫完整備份與舊格式相容

系統 SHALL 在完整備份、ZIP 匯出與覆蓋還原中包含資料庫定義、欄位值及儲存檢視，並可還原尚未包含資料庫欄位的舊備份。MUST 校驗新設定與值，無效資料不得發布為成功備份或部分還原。

#### Scenario: 資料庫備份往返
- **WHEN** 使用者備份含資料庫、欄位值、筆記正文及檢視的內容並覆蓋還原
- **THEN** 完整設定、列值及正文恢復，新文件世代隔離舊裝置
- **自動化驗證**: `DB-09`；Playwright：建立 fixture、下載 ZIP、變更內容再還原，斷言清單、屬性、檢視、正文與舊世代拒絕。

#### Scenario: 舊備份與無效新設定
- **WHEN** 還原不含新欄位的舊備份或校驗含無效資料庫設定的新備份
- **THEN** 舊備份正常恢復為一般頁面，無效新備份被拒絕
- **自動化驗證**: `DB-10`；Playwright：測試入口建立舊格式及無效設定 fixture，斷言還原成功／拒絕與原正式資料保留。
