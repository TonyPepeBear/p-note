# 備份與還原規格草案

狀態：審閱草案。90 天保留已確認；頻率、擷取界線及操作介面依 Q8 確認，完整恢復須通過 V4。

驗證採 TDD 且全部自動化，方法與限制見 [自動化驗證計畫](../../../../../docs/automated-validation.md)。以下 ID 為待實作測試的追蹤編號，並非已通過結果。

## Purpose

讓私人筆記、日記、頁面階層與圖片在事故或誤操作後有可驗證的完整復原資料，保留九十天並支援可攜匯出；還原應保護現況、隔離舊裝置狀態，且不使舊登入憑證重新有效。

## ADDED Requirements

### Requirement: 90 天完整備份

系統 SHALL 保留成功備份 90 天，包含頁面清單、階層、日記日期、垃圾桶狀態、可恢復內文原始狀態及所需圖片。頻率與到期界線依 Q8 確認。

#### Scenario: 恢復保留中的備份

- **WHEN** 擁有者選擇保留期內的成功備份
- **THEN** 可取得完整可恢復資料，不能只取得文字而缺少階層或必要圖片
- **自動化驗證**: `BACKUP-01`；Workers 整合：固定時鐘並在 90 天保留期內恢復 fixture 備份，斷言頁面、階層、日期、垃圾桶、內文與圖片雜湊一致。

#### Scenario: 到期清理

- **WHEN** 系統清理超過保留期的備份
- **THEN** 不刪除仍被其他保留中備份引用的檔案，不使仍有效備份失去完整性
- **自動化驗證**: `BACKUP-02`；Vitest／Workers 整合：依 Q8 到期界線測試前一刻、邊界與之後，含共享圖片引用，斷言僅刪到期備份且有效備份仍完整。

### Requirement: 備份完整性與界線

系統 MUST 記錄格式、擁有者對應、文件世代、持久檢查點、擷取時間與檔案校驗資訊；只有全部必要項目驗證通過才回報成功。尚未送達雲端的離線修改不屬於雲端備份。

#### Scenario: 部分檔案失敗

- **WHEN** 任一必要文件或圖片擷取／校驗失敗
- **THEN** 本次備份標記失敗，不取代最新成功備份，不宣稱完整
- **自動化驗證**: `BACKUP-03`；Workers 整合：逐項注入文件／圖片讀取或校驗失敗，斷言備份失敗、沒有成功清單且最新成功備份指標不變。

#### Scenario: 擷取期間世代切換

- **WHEN** 頁面世代在備份擷取期間改變
- **THEN** 系統重試取得相容資料或使備份失敗，不混合不相容世代
- **自動化驗證**: `BACKUP-04`；Workers 整合：擷取中切換文件世代，斷言重試後清單一致或任務失敗，不存在混合世代成功備份。

#### Scenario: 時間窗備份提案

- **WHEN** 依 Q8 核准的逐篇擷取方式產生備份
- **THEN** 清單列出整體時間窗與各篇檢查點，不宣稱全站同一瞬間，也不宣稱包含原裝置尚未同步修改
- **自動化驗證**: `BACKUP-05`；Workers 整合：固定各文件擷取時刻並保留未送達離線更新，斷言清單時間窗／檢查點正確且不包含尚未上雲修改。

### Requirement: 私有匯出與憑證隔離

系統 SHALL 提供擁有者可下載的完整產品匯出；MUST 驗證下載權限，排除 session、magic link 憑證與服務密鑰並保留可映射的擁有者識別。操作形式待 Q8 確認。

#### Scenario: 完整匯出

- **WHEN** 擁有者下載產品資料
- **THEN** 匯出包含恢復頁面、內文與圖片所需資料及清單，不含登入憑證或服務密鑰
- **自動化驗證**: `BACKUP-06`；Workers 整合＋Playwright：自動下載並解析完整匯出，斷言檔案集合、擁有者映射與校驗值；掃描確定沒有 session／magic link／測試服務密鑰。

### Requirement: 覆蓋還原保護

系統 MUST 在覆蓋還原前保存現況、驗證備份、暫停受影響寫入；只有完整恢復驗證通過才切換正式資料，不發布半套還原。

#### Scenario: 還原中斷

- **WHEN** 還原準備或驗證階段失敗
- **THEN** 保留可恢復現況與失敗資訊，不讓用戶端使用部分新、部分舊的正式資料
- **自動化驗證**: `BACKUP-07`；Workers 整合：在還原準備／驗證／切換中斷點注入失敗，斷言現況或可恢復狀態完整，正式入口無半套資料。

#### Scenario: 正確恢復

- **WHEN** 還原完成
- **THEN** 頁面、階層、日期、內文與圖片可使用，擁有者對應正確，舊 session 或登入連結不因還原重新有效
- **自動化驗證**: `BACKUP-08`；Workers 整合＋Playwright：在乾淨儲存自動恢復完整 fixture，斷言資料與圖片一致、索引重建、擁有者正確，舊登入憑證仍被拒絕。

### Requirement: 還原後舊裝置隔離

系統 MUST 在覆蓋還原後隔離還原前裝置狀態；舊修改不得自動合併回還原後文件。

#### Scenario: 舊裝置重新連線

- **WHEN** 裝置帶著還原前的離線修改重連
- **THEN** 先停止舊世代寫入，讓擁有者檢視或另存本機修改，不破壞已還原資料
- **自動化驗證**: `BACKUP-09`；Workers 整合＋Playwright：還原後重連舊離線 context，斷言舊世代寫入拒絕、恢復內容不變且另存保留原裝置修改。
