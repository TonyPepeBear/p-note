## MODIFIED Requirements

### Requirement: 電腦與手機必要操作

系統 SHALL 在電腦與手機提供可用的區塊插入／移動／刪除與頁面導覽；手機操作 MUST 不只依賴懸停或拖曳，必要控制可由鍵盤或觸控到達。可視範圍縮小時 MUST 主動捲動游標所在區塊，保留頂端導覽與手機格式工具列所需間距。

#### Scenario: 手機調整區塊

- **WHEN** 使用者在手機編輯
- **THEN** 可用可點選選單插入、調整與刪除區塊，可視範圍因鍵盤佔位縮小時仍保持編輯焦點並能讀寫內容
- **自動化驗證**: `EDIT-04`；Playwright：手機觸控與桌面鍵盤自動操作選單，斷言插入／移動／刪除後區塊序列；縮小 viewport 模擬鍵盤佔位，檢查焦點及可視編輯區。
