## MODIFIED Requirements

### Requirement: 多裝置即時內文同步

系統 SHALL 自動同步同一頁面及世代的內文修改，合併不同裝置的可合併編輯；重複送達或到達順序不同不得造成重複內容。 空媒體區塊、HTTP(S) 外部媒體與 tel／ftp 連結 MUST 能連同同步區塊往返，仍拒絕危險協定及越權資產。

#### Scenario: 兩裝置編輯不同段落

- **WHEN** 電腦與手機連線編輯同一篇不同段落
- **THEN** 兩邊看到合併後一致內容，不要求使用者處理整篇版本衝突
- **自動化驗證**: `SYNC-01`；Playwright＋Workers 整合：兩個隔離 context 併發修改不同段落，等待有界同步條件，斷言兩端內文與持久快照等於預期合併結果。

#### Scenario: 重送更新

- **WHEN** 確認遺失而重送同一更新
- **THEN** 文件不重複插入內容，該提交仍可取得持久保存確認
- **自動化驗證**: `SYNC-02`；Workers 整合：自動丟棄確認並重送同一更新，斷言內容不重複、提交可確認且重啟後內容一致。
