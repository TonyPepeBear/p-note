## MODIFIED Requirements

### Requirement: 私有匯出與憑證隔離

系統 SHALL 提供擁有者可下載的完整產品匯出；MUST 驗證下載權限，排除 session、magic link 憑證與服務密鑰並保留可映射的擁有者識別。設定頁提供完整 ZIP 下載與成功備份覆蓋還原。 下載失敗 MUST 顯示可讀錯誤而非另存錯誤回應為 ZIP；建立及還原的非 JSON 錯誤 MUST 有可讀替代訊息。

#### Scenario: 完整匯出

- **WHEN** 擁有者下載產品資料
- **THEN** 匯出包含恢復頁面、內文與圖片所需資料及清單，不含登入憑證或服務密鑰
- **自動化驗證**: `BACKUP-06`；Workers 整合＋Playwright：自動下載並解析完整匯出，斷言檔案集合、擁有者映射與校驗值；掃描確定沒有 session／magic link／測試服務密鑰。

### Requirement: 覆蓋還原保護

系統 MUST 在覆蓋還原前保存現況、驗證備份、暫停受影響寫入；只有完整恢復驗證通過才切換正式資料，不發布半套還原。 大型還原 MUST 避免單一 SQL 參數超限，原子切換後 MUST 以可重試清理釋放失效資產、歷史與未使用房間。

#### Scenario: 還原中斷

- **WHEN** 還原準備或驗證階段失敗
- **THEN** 保留可恢復現況與失敗資訊，不讓用戶端使用部分新、部分舊的正式資料
- **自動化驗證**: `BACKUP-07`；Workers 整合：在還原準備／驗證／切換中斷點注入失敗，斷言現況或可恢復狀態完整，正式入口無半套資料。

#### Scenario: 正確恢復

- **WHEN** 還原完成
- **THEN** 頁面、階層、日期、內文與圖片可使用，擁有者對應正確，舊 session 或登入連結不因還原重新有效
- **自動化驗證**: `BACKUP-08`；Workers 整合＋Playwright：在乾淨儲存自動恢復完整 fixture，斷言資料與圖片一致、索引重建、擁有者正確，舊登入憑證仍被拒絕。
