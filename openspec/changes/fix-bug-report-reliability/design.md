## Context
既有編輯器允許空媒體與 HTTP(S) 外部媒體，伺服器卻只允許本機圖片；所有 metadata 草稿共用阻塞判斷。跨儲存操作需要可重試清理，不能先刪仍引用的資料。

## Decisions
- 媒體接受空值、合法 HTTP(S) 外部網址與經擁有者驗證的本機引用；連結接受 tel／ftp，拒絕主動腳本協定。
- 同格保存以 Promise 尾鏈序列化並讀取最新草稿；400／409 不自動重送、不阻塞其他操作，仍保留可修正的輸入。
- 選項依設定順序排序，多選先正規排序；所有空值固定排最後。尚未填值的篩選不套用，未設定勾選視為否。
- 欄位管理維持各檢視順序，類型／選項變更移除失效篩選；不以垃圾桶資料阻擋設定。
- 標題保存只在輸入未再改變時更新畫面；popstate 先保存，失敗恢復目前網址。
- OAuth CSP 僅額外允許已驗證 callback 來源；成功完成授權後才寫連線紀錄。
- 還原 SQL 以單一原子批次搭配 JSON 分塊，仍存在頁面的歷史與圖片清單保留，清理無對應頁面歷史及被覆寫資產；清理以持久佇列確保可重試；未發布 DO 可明確丟棄。
- 上傳去除 JPEG APP1／PNG eXIf／WebP EXIF 個資及 XMP，僅白名單保留顯示方向以避免手機照片旋轉；保留壓縮像素；JPEG 接受 EOI 後附加資料並移除尾端以避免殘留定位資訊。

- 手機縮放時先沿用編輯器的游標捲動，再以目前內容區塊做原生捲動，搭配 scroll-margin 避免工具列遮擋；原始編輯器已重現段落底部超出一像素。

## Validation
以 Chromium 回歸測試先證明失敗，再跑受影響 E2E、Workers、型別、建置與規格檢查；完成驗收跑完整產品三瀏覽器測試。
