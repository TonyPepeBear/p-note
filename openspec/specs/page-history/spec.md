# page-history Specification

## Purpose
為筆記與日記保存可持久讀取的標題及正文版本，提供私人歷史清單、唯讀預覽與安全單頁還原，並在離線、跨裝置及還原中斷時保護目前內容。

## Requirements

### Requirement: 保存頁面版本

系統 SHALL 為一般筆記及日記保存標題與正文的自動版本，並允許手動建立版本。首次編輯前保留基準，連續編輯最多每五分鐘建立自動版本，開啟歷史時補存最新內容並去重；手動版本不受時間限制。已發布的版本 MUST 來自已持久保存的正文；資料庫容器不提供此功能。 其他頁面的刪除或單頁還原 MUST 不阻止此頁建立版本；版本寫入失敗的未引用物件 SHALL 清理。

#### Scenario: HIST-01 自動與手動版本
- **自動化驗證**: `HIST-01`；Workers 與 Playwright 修改正文及標題、手動建立版本，斷言重開後仍可取得先前內容、自動快照去重且沒有未持久保存的版本。
- **WHEN** 頁面正文或標題保存成功，或使用者手動建立版本
- **THEN** 版本歷史可取得對應標題與正文，並區分版本來源

### Requirement: 瀏覽版本歷史

系統 SHALL 從頁面操作提供版本歷史，依固定順序倒序分頁並提供唯讀預覽。預覽 MUST 保留區塊格式且不可變更目前文件。

#### Scenario: HIST-02 清單與格式預覽
- **自動化驗證**: `HIST-02`；Workers 建立超過一頁且同時間的版本，斷言分頁沒有重複或漏失；Playwright 預覽含格式與巢狀區塊的版本，斷言唯讀、目前正文不變、手機寬度無水平溢出。
- **WHEN** 使用者開啟歷史並選擇版本
- **THEN** 顯示版本時間、來源、標題與唯讀正文，可繼續載入較早版本

### Requirement: 安全還原單頁

系統 SHALL 在確認後還原單頁標題及正文，還原前先保存目前版本，並建立新的同步世代。還原 MUST 保留頁面位置、日記日期、欄位值及其他頁面。

#### Scenario: HIST-03 還原與還原前保護
- **自動化驗證**: `HIST-03`；Workers 與 Playwright 還原舊版本，斷言標題及正文恢復、目前內容另存版本且可再還原、世代變更、其他頁面及結構欄位不變，重開保留結果。
- **WHEN** 使用者確認還原歷史版本
- **THEN** 目前頁面切換至目標標題及正文，還原前內容仍可從歷史取得

#### Scenario: HIST-04 舊端與重試隔離
- **自動化驗證**: `HIST-04`；Workers 注入還原中斷並以同一操作識別重試，斷言可完成且不重複覆蓋後續編輯；Playwright 保持第二個 context 的舊文件，斷言還原後舊內容隔離且不污染新世代。
- **WHEN** 還原期間中斷、重試，或舊裝置重新連線
- **THEN** 操作可安全重試，舊世代內容不得自動合併回已還原文件

### Requirement: 私人存取與失敗處理

系統 SHALL 以網站登入、擁有者及目前頁面可見性限制歷史讀寫。離線或服務失敗 MUST 明確顯示且保留正文及可重試狀態。

#### Scenario: HIST-05 歷史權限邊界
- **自動化驗證**: `HIST-05`；Workers 以未登入、跨擁有者、跨頁版本、垃圾桶、跨來源及 API key 請求歷史入口，斷言拒絕且不洩漏版本內容。
- **WHEN** 未具頁面存取權限的請求嘗試讀取、建立或還原版本
- **THEN** 請求遭拒，原頁與版本內容不變

#### Scenario: HIST-06 離線與錯誤重試
- **自動化驗證**: `HIST-06`；Playwright 注入清單、預覽及還原請求失敗並切換離線，斷言錯誤可重試、不冒充空歷史、正文保留且離線不執行還原。
- **WHEN** 裝置離線或版本請求失敗
- **THEN** 顯示可理解的狀態並保留目前頁面，恢復連線後可重試
