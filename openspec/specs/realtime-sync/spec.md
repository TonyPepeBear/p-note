# realtime-sync Specification

## Purpose
讓同一擁有者在電腦、手機與不同分頁同步內文，在斷線後保留已下載文件的修改並安全重連，且明確區分已交換與已持久保存；刪除、權限失效及備份還原不得被舊裝置更新繞過。

## Requirements

### Requirement: 多裝置即時內文同步

系統 SHALL 自動同步同一頁面及世代的內文修改，合併不同裝置的可合併編輯；重複送達或到達順序不同不得造成重複內容。 空媒體區塊、HTTP(S) 外部媒體與 tel／ftp 連結 MUST 能連同同步區塊往返，仍拒絕危險協定及越權資產。

#### Scenario: 兩裝置編輯不同段落

- **WHEN** 電腦與手機連線編輯同一篇不同段落
- **THEN** 兩邊看到合併後一致內容，不要求使用者處理整篇版本衝突
- **自動化驗證**: `SYNC-01`；Playwright＋Workers 整合：兩個隔離 context 併發修改不同段落，等待有界同步條件，斷言兩端內文與持久快照等於預期合併結果。

#### Scenario: 重送更新

- **WHEN** 確認遺失而重送同一更新
- **THEN** 文件不重複插入內容，該提交仍可取得持久保存確認
- **自動化驗證**: `SYNC-02`；Workers 整合：自動丟棄確認並重送同一更新，斷言內容不重複、提交可確認且重啟後內容一致。

### Requirement: 持久保存確認與狀態

系統 MUST 只在本次提交已持久保存後顯示已儲存，並區分本機保存、同步中及雲端保存。確認舊提交不得覆蓋新修改的待保存狀態。

#### Scenario: 保存失敗

- **WHEN** 雲端儲存失敗，即使同步連線有效
- **THEN** 系統不顯示已儲存，保留本機修改並提供失敗／重試狀態
- **自動化驗證**: `SYNC-03`；Workers 整合＋Playwright：注入寫入失敗，斷言沒有持久確認／成功廣播、UI 不顯示已儲存且本機修改保留。

#### Scenario: 確認期間繼續輸入

- **WHEN** 使用者送出一次修改後繼續輸入，再收到前一次確認
- **THEN** 只有前一次提交被確認，後續修改仍待保存
- **自動化驗證**: `SYNC-04`；Workers 整合＋Playwright：延遲第一筆確認，在此期間輸入第二筆，斷言第二筆仍待確認，只有其確認後 UI 才顯示已儲存。

#### Scenario: 刪除修改

- **WHEN** 使用者只刪除文字或區塊而沒有新增文字
- **THEN** 刪除操作也須取得持久保存確認，不因同步摘要相同而誤判已保存
- **自動化驗證**: `SYNC-05`；Workers 整合：只刪文字／區塊並保留相同新增操作摘要，斷言提交確認、持久刪除狀態與重啟後文件結果。

### Requirement: 伺服器重啟恢復

系統 MUST 在同步服務休眠、重啟或快照整理中斷後，恢復所有已持久確認的內文，不以空文件替代失敗載入。

#### Scenario: 保存後重啟

- **WHEN** 使用者已收到持久確認，服務重啟且所有用戶端重新連線
- **THEN** 確認內容仍存在並可繼續同步，不要求本機快取救回已確認資料
- **自動化驗證**: `SYNC-06`；Workers 整合：取得確認後清除用戶端快取並以 abortAllDurableObjects 重啟實例；另以 evictDurableObject 驗證休眠／喚醒，斷言只靠持久資料仍可恢復。

#### Scenario: 快照整理中斷

- **WHEN** 整理持久資料時中斷
- **THEN** 再次載入可恢復整理前或整理後的完整已確認狀態，不漏掉其間新更新
- **自動化驗證**: `SYNC-07`；Workers 整合：在快照保存／紀錄清理中斷點注入失敗並重啟，斷言所有已確認更新及已持久保存的同期新更新保留，不接受空文件。

### Requirement: 已下載內文離線編輯

系統 SHALL 保存已下載頁面的本機內文狀態，離線期間可編輯，重連同世代後合併；未下載頁面不得宣稱離線可編輯。新增頁面、標題／階層異動及圖片上傳必須連線。

#### Scenario: 手機離線再重連

- **WHEN** 手機離線修改已下載內文，電腦同時在線修改
- **THEN** 手機保留本機內容，重連且權限／世代有效後合併雙方更新並等待持久確認
- **自動化驗證**: `SYNC-08`；Playwright＋Workers 整合：隔離手機 context 斷網，雙端修改後重連，斷言本機重新載入、合併結果與各提交持久確認。

#### Scenario: 無本機文件或本機儲存失敗

- **WHEN** 頁面未下載或本機保存不可用
- **THEN** 系統明確提示限制或失敗，不顯示修改已保存在此裝置
- **自動化驗證**: `SYNC-09`；Playwright：清空目標頁快取或注入 IndexedDB 寫入失敗，斷言限制／錯誤文字且不出現本機保存成功狀態。

### Requirement: 刪除與還原世代隔離

系統 MUST 拒絕已刪除頁面、舊世代或無權限連線的更新；保留合法擁有者原裝置修改供檢視或另存，不自動復活頁面或把舊狀態合併到還原文件。

#### Scenario: 離線期間頁面被刪除

- **WHEN** 裝置重連的頁面已被刪除
- **THEN** 系統停止該頁同步，讓擁有者選擇還原或另存，而非自動寫回
- **自動化驗證**: `SYNC-10`；Workers 整合＋Playwright：手機斷網修改，伺服器刪頁後重連，斷言拒絕寫回、刪除狀態不變與還原／另存入口存在。

#### Scenario: 備份還原後重連

- **WHEN** 裝置帶著還原前的世代與離線修改重連
- **THEN** 系統隔離舊修改，載入新世代資訊並提供檢視／另存入口，不自動合併
- **自動化驗證**: `SYNC-11`；Workers 整合＋Playwright：備份還原換世代後重連舊 context，斷言舊更新未套用、新資訊已載入，本機舊內容仍可檢視／另存。

### Requirement: 中文與跨分頁同步

系統 MUST 在輸入法與多分頁情境保持已完成內文一致，不跨使用者或世代混用本機狀態。

#### Scenario: 同瀏覽器兩分頁

- **WHEN** 兩分頁編輯同一有效文件
- **THEN** 更新可收斂且待確認狀態正確，不以整篇草稿覆蓋另一分頁內容
- **自動化驗證**: `SYNC-12`；Playwright：同 context 兩分頁重播併發及 composition 事件，斷言內容收斂、提交狀態正確且不同使用者／世代未共用快取。
