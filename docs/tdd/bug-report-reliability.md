# 潛在 bug 報告修復驗證

## 行為與修復範圍

| 報告項目 | 修復與自動化驗證 |
| --- | --- |
| 同步引用遇到空白／外部媒體、tel／ftp 後停存 | 共用 JSON 驗證接受合法佔位與網址，仍驗證私人資產；SB-03 瀏覽器保存、備份及重開，既有 KEY／SB Workers 權限測試。 |
| OAuth 跨來源 callback 被 CSP 擋住 | 同意頁只加入已驗證 callback 來源；PLUGIN-05 實際本機 HTTP callback，驗證同意與拒絕。 |
| 其他頁面操作阻止首個歷史快照 | 只阻擋涉及本頁的 operation member；HIST-01 同時存在另一頁刪除操作，仍可建立版本。 |
| 永久欄位錯誤卡住整庫 | 400／409 保留錯誤輸入並退出自動重送；DB-06 無效網址後仍能新增筆記。 |
| 同格請求亂序 | 等待尾鏈後讀取最新草稿；DB-06 攔住首個請求連續切換四次，斷言同時最多一筆及最後值。 |
| 單選／多選按 UUID 排序 | 依選項設定順序比較，多選先正規化；DB-05 單元測試。 |
| 欄位管理覆蓋檢視順序、類型／選項變更留下無效篩選 | 保留各檢視 columns，保存前清理失效篩選；DB-05 變更類型並斷言欄序及篩選。 |
| 篩選此欄立刻空白、數字空值被當 0 | 未填完的非空值運算子不參與 AND／OR；DB-05 單元測試與既有 DB-13 互動測試。 |
| 上一頁遺失標題、舊回應覆蓋新輸入 | popstate 先保存；標題保存及遠端屬性更新均保護後續輸入；UX-02／UX-17 攔截回應與實際 history 操作。 |
| 空值排序、未設定勾選值 | 空值排序固定最後；勾選未設定視為否；DB-05 單元測試。 |
| 篩選後隱藏選取列仍批次刪除 | 篩選／組合改變時清空選取；既有 DB-16 批次測試。 |
| 垃圾桶資料阻擋欄位變更 | 保留相容性檢查以免還原後資料失效；錯誤明確指出垃圾桶筆記並提供處理方式。DB-12 斷言拒絕原因及原筆記可正常還原。 |
| metadata 被誤判本機草稿 | 讀取 IndexedDB 的 downloaded 標記後才顯示歷史草稿；LFN-05 metadata 世代不同且無正文仍可正常開頁。 |
| start 失敗洩漏資源 | 失敗時釋放 provider、IndexedDB persistence 與 Y.Doc；LFN-05 及既有離線／重連測試。 |
| 跨分頁登入後原分頁無法恢復 | focus／online／登入標記變更時重驗 session；AUTH-06 雙分頁驗證。 |
| 驗收發現的既有手機游標遮擋 | 原始編輯器重現段落超出可視區一像素；縮放後以原生捲動及區塊間距避開導覽／格式工具列；EDIT-FOCUS-01 三瀏覽器驗證。 |
| 開啟中的頁面選單卸載後鎖住導覽 | 卸載時釋放父元件的選單狀態；既有 UI-04 選單及手機導覽測試。 |
| 還原圖片、孤兒版本及失敗候選物件累積 | migration 0014 持久記錄回收，寬限一小時後由每日排程執行；保留有效頁面歷史及圖片清單，只回收失效物件；BACKUP-06／HIST-06 故障注入與 R2／D1 斷言。 |
| fork／duplicate／同步區塊候選 DO 沒發布 | prepare 前登記清理，回收時確認不再被頁面、還原引用；SYNC-06 斷言候選清空且活躍房間保留。 |
| 大型還原 SQL 參數過大 | metadata 分段暫存後原子切換，碰撞檢查只分批傳 ID；BACKUP-08 以超過 2 MiB metadata 還原並驗證內容、冪等及暫存清空。 |
| ZIP 下載與備份錯誤回應 | 先驗證成功狀態及 MIME 才建立下載，非 JSON／空訊息使用可讀替代文字；BACKUP-06 攔截 HTML 500 與無 message JSON，斷言無下載。 |
| OAuth 未完成就留下連線 | completeAuthorization 成功後才發布 mcp_grants；既有 PLUGIN／MCP 權限測試與外部 callback 回歸。 |
| 寄信失敗洩漏 owner Email | 失敗仍回一致條件式訊息，內部只記一般錯誤；AUTH-04／MAIL-02／MAIL-03 驗證撤銷 token 且不建立 session。 |
| JPEG EOI 後附加資料拒收、EXIF 隱私 | 允許合法 JPEG 後附加資料；保存時去除尾端與 GPS／XMP 等 metadata，僅白名單保留顯示方向，壓縮像素與動畫保留；ASSET-03 單元及 Workers 驗證格式、雜湊與邊界。 |

## 驗證方法

Red 由原始程式重現：同步保存失敗、外部 OAuth callback 無法重導、無效欄位阻止新增，以及排序錯誤。標題另外使用原始 editor 再跑同一回歸，斷言最後輸入被先前回應覆蓋。

Green 使用最終程式執行新增 Chromium 回歸、單元、Workers、完整三瀏覽器 E2E、型別、建置及規格檢查。完整報告與重跑的彙總數量另存於 [驗證結果](bug-report-reliability-results.json)；不提交含 cookie、授權碼或登入連結的原始 trace／log。

清理只涵蓋這次變更追蹤的候選、還原時可辨識的舊引用；先前已失去索引且未被追蹤的歷史孤兒物件不會在部署時直接回溯掃除。歷史版本與備份中的原始圖片不會重新編碼；隱私清理套用於新上傳。
