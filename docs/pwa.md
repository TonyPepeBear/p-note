# PWA 安裝與離線使用

p-note 可安裝到電腦或手機，使用與瀏覽器相同的私人帳號。登入頁與側欄提供「安裝 p-note」；支援的瀏覽器會顯示原生安裝提示，其餘會顯示選單操作說明。

- iPhone／iPad：以 Safari 開啟網站，選「分享」→「加入主畫面」。
- Android／電腦：使用瀏覽器的「安裝應用程式」或「加入主畫面」。是否提供安裝由瀏覽器決定。
- 從獨立視窗開啟後隱藏安裝按鈕；取消安裝不影響使用。

## 離線範圍

登入前就會下載應用程式外殼；下載完成後可離線重開介面。登入、首次下載筆記與雲端同步仍需要網路。已下載的筆記可離線刷新、編輯與保存到本機，恢復連線後沿用原本的權限驗證與同步機制。未下載的筆記會明確顯示「尚未下載」。

HTTP 快取只保存公開外殼、圖示與靜態資源，不保存私人 API、登入確認、同步連線或第三方分析內容；正文仍由原本的 IndexedDB 儲存。導覽的快取鍵統一為 `/`，不記錄筆記 ID 或登入參數。

瀏覽器可能清除網站儲存，清除後必須重新連線下載；安裝本身不等於永久保存或備份。離線使用請等筆記顯示「本機已儲存」。

## 應用程式更新

新版外殼完整下載後，側欄或登入頁會出現「更新 p-note」。按下後暫停輸入、保存正文與中繼資料，再套用新版並重新載入目前分頁；保存失敗時顯示錯誤、恢復編輯並保留草稿。其他開啟中的分頁不會被強制重新載入。

既有的站內換頁版本偵測仍沿用原流程。雜湊靜態資源優先讀取快取，舊版資源保留給尚未關閉的分頁，避免發布後伺服器移除舊檔而無法載入。這會增加裝置儲存用量，並受瀏覽器儲存清除政策管理。Service Worker 更新不會刪除筆記 IndexedDB。

## 開發與自動化驗證

`npm run build` 會將本次 JS／CSS、根入口、manifest 與圖示寫入版本化的 Service Worker 預快取清單；版本由資源內容與 Service Worker 產生。首次安裝必須完整下載清單，新版不在安裝時直接強制啟用。圖示可用 `node scripts/generate-pwa-icons.mjs` 重建，無外部套件相依。

PWA 的離線驗證使用建置後入口；`npm run dev` 的開發模組不在正式靜態資源白名單內。Service Worker 需要 HTTPS 或 localhost。

驗收情境為 PWA-01～06，見 [PWA E2E](../tests/e2e/pwa.spec.ts)、[Service Worker 單元測試](../tests/unit/service-worker.test.ts)。`npm run test:spec-coverage -- --pwa` 檢查各情境的必需執行環境；建置後以本機 HTTPS smoke 驗證登入、wss 與離線刷新。正式發布沿用既有 Actions，發布成功後結束，不執行額外網站 HTTP 檢查。
