# 筆記連結與反向連結

在筆記或日記正文輸入 `[[`，再輸入頁面標題搜尋。方向鍵與 Enter 可選取，也可直接點選結果；Esc 保留原文字。同名筆記以頁面 ID 區別，日記顯示日期。程式碼區塊不開啟此選單。

插入後成為一般文字連結，可以使用編輯器既有連結工具修改或移除。點連結會先保存草稿再站內換頁；修改鍵可使用瀏覽器的新分頁操作。頁面以固定 ID 連結，改名不會失效；正文中的文字保留插入時標題，不自動改寫。目標在垃圾桶時沿用既有還原入口。

頁面正文／資料庫下方的「反向連結」列出引用自己的來源頁面，點來源即可返回。同一來源引用多次只列一筆，不列自我引用、外部網址或普通文字。來源改名顯示最新名稱；來源或上層在垃圾桶時排除，還原後恢復。查詢需登入，其他帳號及舊正文世代不列入。

已下載的正文連結可離線編輯與刷新；離線搜尋只提供本帳號快取的頁面 metadata，能否開啟仍取決於目標正文是否已下載。反向連結需連線，會於正文同步後更新，每三秒及視窗取得焦點時刷新；讀取失敗顯示可重試訊息，不冒充沒有引用。

JSON 正文 API 使用既有原生 `link` 格式，例如 `{"type":"link","href":"/?page=example-page","content":"範例筆記"}`。完整備份／ZIP 保留正文連結；覆蓋還原從新世代重建反向索引，不備份衍生索引。新 migration 向既有 page_search 加入 linked_pages，不變更既有正文或備份版本。既有手動插入的同格式連結於房間同步／重啟後納入索引。

自動化規格涵蓋 LINK-01～06；測試與部署證據見 [開發驗收紀錄](tdd/note-links.md)。
