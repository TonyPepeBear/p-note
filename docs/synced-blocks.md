# 同步區塊

頁面工具列的「同步區塊操作」可以建立空白同步區塊、將目前區塊或選取的多個區塊轉成同步內容，以及引用既有同步區塊。輸入 `/` 也可以新增空白同步區塊。

每個同步區塊都有外框，內含複製、解除同步及引用頁面清單的按鈕。複製後貼到其他筆記、日記或同一頁，會指向同一份內容。同頁多個引用只計一個使用頁面；垃圾桶及被上層隱藏的頁面不列入引用數。

解除同步將該位置轉回一般區塊，保留當下內容。刪除引用只移除該位置；刪除最後引用後，仍可由「引用既有同步區塊」找回原 ID 與內容。

開啟過的引用內容會保存在本機，可以離線編輯並於重連後合併。未下載的內容離線時顯示「離線無法載入」，不能建立可寫的空白替代內容；建立新的同步區塊需要連線。載入或保存失敗只在該區塊提示，其他內容仍可編輯。頁面必須等所有引用內容完成持久保存，才會顯示「雲端已儲存」。

同步正文支援原有區塊、圖片、程式碼與 `[[` 筆記連結，禁止再放入同步引用。搜尋同步文字會找到每個可見引用頁，反向連結會將它們各列一次。

## 儲存與介面

頁面 Yjs 文件只保存 `syncedBlock` 節點，其 `props.syncedBlockId` 指向另一份獨立 Yjs 正文。所有存取皆驗證擁有者；同步連線還會核對來源頁的實際持久引用與目前世代。

頁面 JSON 預設只回傳引用，選擇展開時另提供同步正文。單一同步正文可經 API 或 MCP 讀寫，更新必須提供 ETag；頁面正文 API 只能增刪引用。詳細範例見 [API 文件](api.md)。

90 天備份和 ZIP 含 `synced-blocks/<ID>.yjs` 原始文件，以及 manifest 的 `synced_blocks` 與 `page_synced_blocks` 清單。ZIP 的 `readable/pages/<ID>.md` 在每個引用位置展開內容並標註同步 ID。覆蓋還原會一起切換頁面與同步正文世代，阻止舊裝置自動合併；沒有同步欄位的舊備份仍可還原。

頁面版本歷史只保存同步引用。預覽會顯示唯讀外框與區塊 ID，不會載入目前同步內容；單頁還原恢復引用，不回復同步正文的歷史狀態，並隔離該頁舊世代連線。
