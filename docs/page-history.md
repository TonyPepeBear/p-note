# 頁面版本歷史

筆記與日記的「頁面操作 → 版本歷史」提供自動保存、手動建立、唯讀預覽及單頁還原。時間使用臺北時區。既有頁面從功能啟用後開始累積歷史，無法回推先前未保存的版本。

首次編輯前保留基準，連續編輯最多每五分鐘建立自動版本，開啟歷史時補存目前內容並去重。「建立版本」可立即保留目前標題與正文。版本不設定自動到期；使用者可以逐頁載入較早版本。

還原前會建立「還原前保存」版本，再替換該頁標題與正文。頁面位置、日記日期、資料庫欄位及其他頁面保留。資料庫容器沒有版本歷史入口，其子筆記仍可使用。預覽保留區塊格式、連結及私有圖片，且不會編輯目前文件。

還原使用新同步世代；其他裝置的舊草稿沿用現有隔離與另存機制，不會自動合併回新正文。還原中斷時可重試原操作；重新整理、開啟其他頁面或換到沒有快取的裝置，登入後也會顯示「繼續版本還原」入口。離線時保留正文與本機草稿，版本操作需要連線。資料庫表格的標題欄位更新同樣納入歷史保存。

## 儲存及存取

D1 `page_versions` 保存版本目錄，R2 BACKUPS bucket 的 `versions/` 前綴保存完整 Yjs 快照；發布目錄前驗證持久快照的長度與 SHA-256。目錄以序號倒序分頁，不依賴可能相同的時間戳記。

網站登入的擁有者才可讀寫可見頁面的歷史；垃圾桶、跨頁版本、其他帳號、跨來源及 API key 請求不得取得內容。歷史回應使用 `Cache-Control: no-store`，不存入 PWA 離線快取。

既有整站備份及 ZIP 匯出格式不包含版本歷史；整站還原保留既有歷史資料。版本快照與 90 天整站備份使用不同前綴，既有備份清理不會刪除版本快照。
