# 筆記資料庫

從頂端「新增」選單選擇「新增資料庫」建立獨立資料庫，或在一般筆記的頁面操作建立「新增子資料庫」。資料庫工具列「新增筆記」或表格底部「＋ 新增」原地建立資料列，表格會聚焦新標題；既有筆記可從頁面操作移動至資料庫。點列的開啟連結，正文上方可編輯屬性，正文沿用既有區塊編輯與離線同步。

「管理欄位」可新增文字、數字、日期、單選、多選、勾選與網址；選項名稱與顏色可修改；單選及多選 cell 使用可搜尋的 Combobox，輸入新名稱即可建立彩色選項。已有值的欄位不能直接改成不同型別，已有使用的選項不能刪除，以免資料默默損壞。標題在表格直接編輯；建立與更新時間唯讀。欄位刪除需確認，原穩定欄位 ID 的值保留於筆記與備份，不再顯示。移出筆記也保留原值；移回原資料庫仍能顯示，不會把原值誤套到另一個資料庫同名欄位。

工具列「篩選」「排序」以 Popover 即時套用，不必另按儲存；工具列下方的條件 chip 按 × 可單獨移除。點欄標題可升冪／降冪、篩選此欄、隱藏或編輯自訂欄位。「檢視設定」可即時切換表格／清單、開啟自動換行，並以 Switch 控制欄位顯示、拖曳把手調整順序；鍵盤聚焦把手後按 ↑／↓ 也可排序。標題欄固定在最前方。「新增檢視」可命名新檢視，分頁旁的選單可重新命名、複製及刪除。篩選運算子隨型別提供，單選／多選篩選由選項名稱挑選。時間篩選使用日期輸入，依台北日曆日期判斷；建立／更新時間顯示精簡日期。清單屬性顯示欄位名稱、圖示及彩色選項。每個檢視獨立保存；至少保留一個檢視。檢視工具列的搜尋只針對筆記名稱；全站搜尋仍可找到正文。表格在手機僅於自身區域橫向捲動。

欄標題右緣可拖曳調整欄寬，放開後保存；聚焦把手以 ←／→ 每次調整 20px。每欄 80～1200px，各檢視獨立記憶。自動換行開啟後文字可多行、列高隨內容增長；不提供拖曳列高。表格內捲動時，表頭與第一個標題欄固定。

每列尾端選單可複製、移動或移入垃圾桶；勾選多列後可批次操作。複製包含已保存正文、圖示及屬性，建立獨立筆記世代。批次逐筆完成，遇到失敗保留尚未完成的選取，可修正後重試。

## 保存與限制

屬性及檢視必須連線；顯示已儲存代表 API 已成功寫入。每格旁顯示儲存中／成功的小圖示，失敗標紅並可重試；檢視保存狀態顯示於工具列。失敗保留輸入，可重試或放棄修改；換頁前會等待屬性保存，失敗不跳頁。前景且連線的資料庫每三秒讀取 metadata，背景分頁暫停，恢復可見及連線時立即更新。讀取使用 ETag，資料未變時回空 304，不重複下載整份列；未保存輸入存在時不覆蓋草稿。不同裝置修改不同檢視會合併保留；同一檢視的競爭修改仍拒絕，欄位修改保留資料相容性檢查。正文仍可在下載後離線編輯，屬性不能離線修改。

## 實作維護

資料庫頁面分為協調入口、表格／清單、檢視設定、欄位管理與讀取 hook。API 只往上驗證資料庫祖先鏈，條件讀取相符時不查詢子列。D1 觸發器追蹤資料庫與直接子列的 metadata／生命週期變更；版本不只依賴父頁的 metadata_revision，以免漏掉列更新。

後續若取消輪詢，需要獨立的資料庫 WebSocket 訂閱。目前資料庫入口沒有建立正文編輯器的連線；通知需涵蓋屬性、設定、標題、移動、垃圾桶、還原與正文更新時間，並處理提交後通知失敗及重連補讀。

本次提供表格／清單與筆記管理核心；看板、日曆、內嵌／連結檢視、公式、關聯、彙總、多資料來源與多人權限尚未提供。資料庫不能直接隸屬另一個資料庫，日記也不移入資料庫。自訂欄位最多 50，檢視最多 20，每檢視篩選與排序最多各 20；值文字最多 2000 字元，設定本體最多 64 KiB。

## 備份相容

完整備份與 ZIP 的 version 1 頁面 metadata 增加可選的 database_config 與 property_values。備份包含資料庫設定、各筆記欄位值、儲存檢視與正文；覆蓋還原會同時恢復，並更新正文世代。舊備份缺少新欄位時，恢復為一般頁面及空屬性，無需手動轉換。無效設定／型別會被備份校驗拒絕，不能發布半套還原。
