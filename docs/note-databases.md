# 筆記資料庫

從側欄「新增資料庫」建立獨立資料庫，或在一般筆記的頁面操作建立「新增子資料庫」。資料庫內點「新增筆記」建立資料列；既有筆記可從頁面操作移動至資料庫。點列的開啟連結，正文上方可編輯屬性，正文沿用既有區塊編輯與離線同步。

「管理欄位」可新增文字、數字、日期、單選、多選、勾選與網址；選項名稱可直接修改，新增選項輸入後按 Enter。已有值的欄位不能直接改成不同型別，已有使用的選項不能刪除，以免資料默默損壞。標題在表格直接編輯；建立與更新時間唯讀。欄位刪除需確認，原穩定欄位 ID 的值保留於筆記與備份，不再顯示。移出筆記也保留原值；移回原資料庫仍能顯示，不會把原值誤套到另一個資料庫同名欄位。

「新增檢視」與「檢視設定」可設定表格／清單、名稱、顯示欄位與順序、全部／任一條件篩選與多欄位排序。篩選運算子隨型別提供，單選／多選篩選由選項名稱挑選。每個檢視獨立保存；至少保留一個檢視。檢視工具列的搜尋只針對筆記名稱；全站搜尋仍可找到正文。表格在手機僅於自身區域橫向捲動。

## 保存與限制

屬性及檢視必須連線；顯示已儲存代表 API 已成功寫入。失敗保留輸入，可重試；換頁前會等待屬性保存，失敗不跳頁。前景且連線的資料庫每三秒讀取 metadata，背景分頁暫停，恢復可見及連線時立即更新。讀取使用 ETag，資料未變時回空 304，不重複下載整份列；未保存輸入存在時不覆蓋草稿。不同裝置修改不同檢視會合併保留；同一檢視的競爭修改仍拒絕，欄位修改保留資料相容性檢查。正文仍可在下載後離線編輯，屬性不能離線修改。

## 實作維護

資料庫頁面分為協調入口、表格／清單、檢視設定、欄位管理與讀取 hook。API 只往上驗證資料庫祖先鏈，條件讀取相符時不查詢子列。D1 觸發器追蹤資料庫與直接子列的 metadata／生命週期變更；版本不只依賴父頁的 metadata_revision，以免漏掉列更新。

後續若取消輪詢，需要獨立的資料庫 WebSocket 訂閱。目前資料庫入口沒有建立正文編輯器的連線；通知需涵蓋屬性、設定、標題、移動、垃圾桶、還原與正文更新時間，並處理提交後通知失敗及重連補讀。

本次提供表格／清單與筆記管理核心；看板、日曆、內嵌／連結檢視、公式、關聯、彙總、多資料來源與多人權限尚未提供。資料庫不能直接隸屬另一個資料庫，日記也不移入資料庫。自訂欄位最多 50，檢視最多 20，每檢視篩選與排序最多各 20；值文字最多 2000 字元，設定本體最多 64 KiB。

## 備份相容

完整備份與 ZIP 的 version 1 頁面 metadata 增加可選的 database_config 與 property_values。備份包含資料庫設定、各筆記欄位值、儲存檢視與正文；覆蓋還原會同時恢復，並更新正文世代。舊備份缺少新欄位時，恢復為一般頁面及空屬性，無需手動轉換。無效設定／型別會被備份校驗拒絕，不能發布半套還原。
